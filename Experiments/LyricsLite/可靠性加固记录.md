# 可靠性加固（2026-10-19）

本轮针对异常输入与不完整解码，不调整多语言匹配阈值。仍为实验版本，未替换正式 AI。

## 改动

- PCM 读取前检查非空、4 字节对齐，读取后检查成功及全部采样有限。修复非整帧文件按原始字节数读入较小 float 数组的问题。
- 拒绝非有限窗口边界、非法歌曲时长、空歌词和过大的歌词请求。
- 强制解码未覆盖完整参考 token 时，整个窗口不输出可信时间。
- 解码音频与请求时长偏差超过 1 秒或 1%（取较大值）时明确失败，防止对截断音频输出部分结果。
- Swift 接收候选时验证时间及分数有限、分数在 0–1 内。

## 验证

- 构建、20 项匹配和语言回归通过，便携实验包约 191 MB。
- `python3 Experiments/LyricsLite/reliability_tests.py`：8 项通过，包括空/截断/NaN/Infinity PCM、零/负时长、空/超大歌词。
- `python3 Experiments/LyricsLite/negative_tests.py`：静音、错词、错语种共 9 行均拒绝。
- 中文正常歌曲片段复测 10/13 行，与 V3 相同，耗时 5.68 秒（单次观测）。

尚未解决：重复段落的歧义、部分错误歌词的误接收风险、阿拉伯语低覆盖和混唱定位。上述结果不代表所有语言的歌唱准确率提升；完整多语言矩阵未在本轮重跑。
