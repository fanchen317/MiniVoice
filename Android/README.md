# MiniVoice 安卓版

这是独立的 Android 本地播放器工程，复用 MiniVoice 的产品名称与播放模式。首页提供基于本机歌曲封面的音乐墙、可开合的深色侧栏及底部播放条；左下角设置按钮打开音乐库设置。当前包含系统音乐库或指定文件夹扫描、子文件夹开关、重新扫描、歌曲数量、缓存清理、搜索、歌手与专辑浏览、后台播放及通知栏控制、五种播放模式、收藏、最近播放、歌单和 LRC 文件导入。收藏、歌单及导入的歌词保存在应用本地数据中；音乐文件不会复制或修改。

执行 `Scripts/build-android.sh` 可直接生成 `.build/Android/MiniVoice-debug.apk`。也可在 Android Studio 打开 `Android/`，安装 Android SDK 35 和 Build Tools 35.0.0 后运行 `:app:assembleDebug`。支持 Android 10 及以上。

当前音乐墙实现了封面拼贴和侧栏首屏布局，尚未迁移 Mac 版的自由拖拽、缩放和卡片展开动画；标签编辑、在线歌词和离线 AI 歌词匹配也尚未迁移。安卓系统通过媒体库或系统文件夹选择器读取本机歌曲，不直接读取 Mac 的音乐目录；需将音频文件传到手机。安卓应用的缓存属于私有目录，设置中可查看和清理封面缓存，不能像 Mac 版一样从文件管理器直接打开该目录。
