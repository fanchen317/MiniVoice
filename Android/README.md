# MiniVoice 安卓版

这是独立的 Android 本地播放器工程，复用 MiniVoice 的产品名称与播放模式。首页提供基于本机歌曲封面的音乐墙、可开合的深色侧栏及底部播放条；左下角设置按钮打开音乐库设置。当前包含系统音乐库或指定文件夹扫描、子文件夹开关、重新扫描、歌曲数量、缓存清理、搜索、歌手与专辑浏览、后台播放及系统媒体控制、五种播放模式、收藏、最近播放、歌单和 LRC 文件导入。收藏、歌单及导入的歌词保存在应用本地数据中；音乐文件不会复制或修改。

执行 `Scripts/build-android.sh` 可直接生成 `.build/Android/MiniVoice-debug.apk`。也可在 Android Studio 打开 `Android/`，安装 Android SDK 35 和 Build Tools 35.0.0 后运行 `:app:assembleDebug`。支持 Android 10 及以上。

脚本会依次查找 `ANDROID_HOME`、`ANDROID_SDK_ROOT`、`Android/local.properties` 的 `sdk.dir`，然后查找 Android Studio 常用 SDK 目录、Homebrew 路径和项目的 `.build/android-sdk`。优先使用 Build Tools 35.0.0，也支持更新的稳定版本。显式配置的 SDK 不完整时会给出缺少组件的提示，不会删除已有 APK。自定义路径可这样运行：

```bash
ANDROID_HOME="/你的/Android/sdk" ./Scripts/build-android.sh
```


音乐墙使用与 Mac 版相同的加权封面分割算法，并支持双向拖动、双指缩放、点按卡片聚焦、双击播放和封面缓存；移动端控制方式按触屏适配。尚未迁移标签编辑、在线歌词和离线 AI 歌词匹配。安卓系统通过媒体库或系统文件夹选择器读取本机歌曲，不直接读取 Mac 的音乐目录；需将音频文件传到手机。安卓应用的缓存属于私有目录，设置中可查看和清理封面缓存，不能像 Mac 版一样从文件管理器直接打开该目录。

播放服务向 Android 系统媒体会话提供歌名、歌手、专辑、时长和内嵌封面，并同步播放、暂停、上一首、下一首及进度拖动。锁屏和通知栏中的播放器外观由手机系统决定；应用提供的是数据与控制接口。首页壁纸绘制到透明状态栏后方，按钮按状态栏安全区域下移。

点击系统锁屏或通知栏的媒体卡片会返回音乐墙并定位当前歌曲。触屏按钮使用安卓按下波纹反馈，音乐墙卡片保留按下缩放、聚焦和相邻卡片回流动画；鼠标悬停样式不迁移到触屏。

使用设置中的“添加文件夹”选择音乐目录后，扫描器会在每个歌曲所在目录查找同级 `lrc/` 子目录，例如 `Music/歌名.mp3` 对应 `Music/lrc/歌名.lrc`。优先按音频文件名匹配，找不到时按歌曲标题匹配；开启子文件夹扫描时，每个子目录同样适用。歌词支持 UTF-8、UTF-16 和 GB18030，手动导入的歌词优先于自动匹配文件。通过系统媒体库读取但尚未选定文件夹时，Android 的音频权限不包含旁边的文本歌词文件，请在设置中选择音乐目录以启用自动匹配；添加歌词后使用“重新扫描”。

音乐墙的聚焦卡片会按当前播放进度显示同步歌词及相邻歌词行。卡片上的播放按钮在当前歌曲播放时切换暂停和继续，播放其他歌曲时切换曲目；底部播放条仍可拖动进度。

播放队列与音乐墙工具从底部打开半屏面板。音乐墙工具显示 60%–120% 的缩放比例；底部播放条使用加粗的进度轨道和完整滑块。点按播放条里的歌曲名称定位正在播放的封面，长按名称打开歌词；侧边栏使用较窄的滑入面板，搜索框显示在顶部按钮下方。

底部播放条的上一首、下一首和播放队列图标按安卓触屏尺寸直接绘制，图形和触控区域均比桌面图标适配版本更大。

扫描分为查找文件和读取标签两个阶段：设置中先显示已发现的歌曲数量，再显示已处理/总数、百分比及当前文件名。修改子文件夹开关会重新扫描；扫描期间修改文件夹会在当前扫描结束后自动补扫。扫描异常会恢复可重试状态并保留现有音乐库。

歌曲优先使用音频标签，增加 ID3v2.2/v2.3/v2.4（含 UTF-16 中文标签）的直接读取，避免部分安卓设备将文件名当作歌曲标题。标签缺失时，`026 - 许嵩 - 安琪.mp3` 会回退为歌名“安琪”、歌手“许嵩”。封面依次尝试系统内嵌图片、直接解析 ID3 图片、同目录同名图片或 `cover/folder/front/album` 图片，以及系统专辑封面；音乐墙和系统播放器使用相同的封面读取逻辑。歌词也支持同目录 `.lrc`、增强 LRC 的 `<分:秒.毫秒>` 逐字标记及 `[offset:]`；逐字标记用于还原干净的行文字，当前仍按行同步显示。

执行 `Scripts/test-android.sh` 运行 JVM 解析回归测试；需要 Android SDK 35，可通过 `ANDROID_HOME` 指定 SDK。可额外传入测试样本“026 - 许嵩 - 安琪.mp3”的路径，验证真实文件的 UTF-16 标签及内嵌图片读取。

聚焦卡片沿用 Mac 的上下布局：全宽连续遮罩，顶部歌曲信息，播放状态胶囊，中部自动换行的同步歌词，底部上一首、播放/暂停、下一首、收藏、播放模式、展开/收起、时间与白色细进度条。预览未播放歌曲时只显示信息和播放按钮；点击卡片空白处不会切换播放。窄屏时间独立成行，控制按钮保留 44 dp 触控区域；进度条支持点按和拖动，拖动时不会移动音乐墙。展开后隐藏浮动工具和底部播放条，返回键或收起按钮恢复。


安装提示“与已安装应用签名不同”时，需要使用旧版的原始签名密钥构建更新包。旧脚本的密钥位于旧电脑/旧项目的 `.build/Android/debug.keystore`，Android Studio 的默认密钥通常位于 `~/.android/debug.keystore`。仅复制旧 APK 无法恢复私钥。找回旧密钥并复制到本机后，显式指定：

```bash
MINIVOICE_KEYSTORE="/旧密钥的本机绝对路径/debug.keystore" ./Scripts/build-android.sh
```

可通过 `MINIVOICE_KEY_ALIAS`、`MINIVOICE_STORE_PASSWORD` 和 `MINIVOICE_KEY_PASSWORD` 指定非默认别名与密码；默认对应原调试密钥。脚本和 Gradle 都支持这些变量。未显式指定时，脚本使用 `Android/signing/debug.keystore`，首次会优先迁移本项目 `.build/Android/debug.keystore`，其次迁移 Android Studio 调试密钥，均不存在才创建新密钥；这些操作仅在执行构建脚本时发生。密钥不纳入 Git，请保留备份，以后持续使用相同密钥。

音乐墙搜索按钮改为右上角原位展开：圆形镜片先略微放大，再向左展开成胶囊搜索框，输入区渐显，图标转为薄荷绿；关闭时沿原位收回。展开完成后才唤起键盘，支持清空、搜索键收起键盘和返回键收起搜索框。

定位正在播放的歌曲时，同一歌曲列表会保留镜头、缩放及已展开的卡片；重复定位仅平滑居中，不再收缩后重新展开。快速切换焦点从当前可见布局继续回流，重复墙的目标按回流后的距离选择。多个待执行定位会合并，初次定位在视图尺寸就绪后执行，居中位置避让顶部工具与底部播放条。

扫描最后会执行“缓存封面”阶段：先保存最长边 640 像素的磁盘缩略图，再给整份歌曲列表准备常驻小预览（像素内存预算约 24 MiB）。音乐墙平移、缩放和定位时直接保留预览，高清缩略图使用共享内存/磁盘缓存，不会因内存缓存淘汰而闪回音符占位图，也不会为此重新从音频文件提取封面。音频或同目录图片的修改时间/大小改变后，重新扫描会刷新对应缓存。系统播放器共用封面缓存。

歌词匹配支持所选根目录内共享 `lrc/` 文件夹和各子目录同名歌词，增加编号、全半角及空格归一化匹配；存在同名歧义时不猜测匹配。读取中的请求会在页面退出时失效，回到页面会重新读取，扫描更新歌词来源也会触发重载；临时读取失败可自动重试。界面区分加载中、目录权限失败、未匹配和文件格式异常，避免全部归为“暂无歌词”。纯文本歌词也可显示，仍优先使用带时间戳的内容。更新后执行一次重新扫描以准备封面和更新歌词映射。
