# MiniVoice

轻量原生 macOS 本地音乐播放器，基于 SwiftUI 与 AVFoundation，macOS 13 及以上。

## 已实现

- 在“设置 → 音乐库”配置多个文件夹，启动读取隐藏歌单缓存；支持子目录、重叠目录去重、手动重新扫描、歌曲/歌手/专辑搜索。移除目录不删除文件。
- 播放 MP3、FLAC、M4A、AAC、WAV、AIFF；进度跳转、音量、上一曲/下一曲。双击歌曲开始播放，播放中选择其他歌曲立即切换。
- 文件夹、播放模式自动保存；重启读取各目录的 `.minivoice-playlist.json`，恢复上次歌曲，不自动出声。只有首次无缓存、缓存损坏/扫描范围改变或手动刷新才扫描。
- 每个目录独立保存隐藏歌单（相对路径、歌曲信息、歌词、时长、封面缩略图），原子写入；编辑歌曲后同步更新。缓存不包含音频，未改封面时保留歌曲内的原图。
- 音量和播放模式集中在播放器区域。音量使用 CoreAudio 控制当前 Mac 输出设备，并跟随系统音量与设备变化；不支持软件调音的设备会显示说明。
- 单曲播放（播完停止）、列表播放（末曲停止）、随机播放（一轮不重复且可返回历史）、单曲循环、列表循环。
- 上一曲在播放超过 3 秒时先回到开头，再按一次切换。手动上一曲/下一曲保留播放或暂停状态，顺序模式首尾可切换。
- 设置中配置红色关闭按钮行为：继续后台播放（默认）、暂停播放、退出；支持 Dock 和状态栏重新打开。恢复标准窗口标题栏和关闭/最小化/缩放按钮。
- 主窗口和桌面歌词分别记住位置，主窗口同时记住大小；关闭后重新打开及退出后重启均恢复，支持副屏。原屏幕断开时回退到可见区域。
- ⌘P 播放/暂停，⌘←/⌘→ 上一曲/下一曲；⌘Q 退出。
- 参考提供的绿色 MV 音符，以原生矢量绘制应用图标，构建时生成全尺寸 ICNS。
- 状态栏图标可选隐藏、彩色、纯色（随系统明暗外观变化），设置自动保存；可在 MiniVoice → 设置（⌘,）或状态栏菜单切换。
- 状态栏菜单支持打开主窗口、播放/暂停、上一曲/下一曲和退出。
- 编辑歌曲名称、专辑，逐个添加/移除歌手；文件内以 ` / ` 保存多个歌手，保留名称内部的 `/`（例如 AC/DC）。不同播放器对多歌手的结构化识别可能不同。
- 读取内嵌歌词与封面；没有内嵌歌词时自动读取同名 `.lrc`。
- 导入 LRC/SRT/TXT、编辑歌词，支持多时间标签与 `[offset:...]`。SRT 自动转换成 LRC 时间标签。
- 大字号逐行歌词，当前句高亮，点击歌词跳转，默认自动跟随滚动，可关闭自动跟随。纯文本在编辑器保存时通过本地 AI 自动匹配歌曲并生成 LRC；同步期间显示进度并可取消，失败时可重试或仅保存原文。仍可试听并逐行手动打点。
- 为 MP3、FLAC、M4A 写入名称、歌手、专辑、歌词，以及自定义封面的添加、替换、删除；音频码流复制，不重新编码。
- 写入成功才更新界面；每次保存会在歌曲同级的 `backup/` 文件夹保留 `原文件名.minivoice-backup-UUID` 原文件备份。`backup/` 不会被音乐库扫描；需要恢复时将备份复制回原文件名。备份会累积，可在确认编辑正确后手动删除。
- 歌词写入音频文件本身的 `lyrics` 元数据字段（FLAC 为 Vorbis Comment，MP3/M4A 为各自容器标签）；没有内嵌歌词时，播放器才会读取同名 `.lrc` 文件作为显示回退。

## 运行与部署

```sh
brew install ffmpeg
swift run
```

```sh
swift test
Scripts/deploy.sh
```

部署脚本先构建 release、验证签名，再退出旧版并替换 `/Applications/MiniVoice.app`，最后启动。依赖通过绝对路径查找，Finder 启动不依赖终端 PATH。当前部署面向本机，ffmpeg/ffprobe 需要保留在 Homebrew 安装位置。

单独构建：`Scripts/build-app.sh [debug|release]`，产物在 `.build/MiniVoice.app`。

## 当前边界

- AAC、WAV、AIFF 支持播放，暂不提供完整标签/封面写入，编辑窗口会明确提示。
- 暂无封面裁剪、歌词在线搜索、逐字卡拉 OK、自定义播放列表排序、系统媒体键接入。
- 目录内容变化后点“重新扫描”更新隐藏歌单；启动不自动遍历音频。目录移动后需重新配置，缓存内使用相对路径。歌词推荐 UTF-8。
- 旧版逐文件导入已移除；首次升级需在设置里添加音乐文件夹。
- 本机使用 ad-hoc 签名；分发给其他 Mac 还需处理 ffmpeg 依赖、开发者签名与公证。

## 验证

`swift test` 包含缓存启动不扫描、损坏缓存重建、SRT/LRC 识别、原始封面保留、文件夹递归/去重/移除安全、播放模式边界、随机历史、实际播放结束自动切歌及停止，以及 MP3/FLAC/M4A 文件往返测试：中文标签、多歌手、歌词、封面添加和删除、备份、AVAudioPlayer 可读取，以及保存前后音频码流 SHA-256 一致。

## AI 歌词自动跟随

在“编辑歌曲信息”粘贴纯文本、LRC 或 SRT 后保存。完整时间标签直接使用；缺少时间标签时，后台进程读取当前歌曲音频，使用 [stable-ts](https://github.com/jianfch/stable-ts) + Whisper small 在本机生成逐行时间轴。首次使用自动建立独立 Python 环境并下载依赖和约 461 MiB 模型；之后可离线使用，无需 API Key，歌曲和歌词不上传。结果按编辑器选择保存到文件标签、`lrc/` 或两者，并更新歌单缓存。拖动进度和桌面歌词复用同一时间轴。

- AI 文件位于 `~/Library/Application Support/MiniVoice/LyricsAI/`；使用 Homebrew Python 3.11/3.12 或本机 Xcode Python 3.9，以及现有 FFmpeg。
- 歌名、常见作词/作曲等信息和段落标记保存在 LRC 的 `[note:...]` 元数据中，不参与演唱对齐。歌词正文保留输入顺序和重复段落；已有手动时间点保留，时间冲突时会提示。
- 处理时编辑窗口保持打开，取消后保留输入。只有对齐成功后才写文件；失败可选“仅保存原歌词”。仅保存的纯文本不会自动滚动，可再次打开编辑器保存重试。
- 应输入完整、与当前音频版本一致的歌词。复杂伴奏、现场版、漏句或副歌省略可能导致失败或偏移；可手动打点校正。当前为逐行跟随，不是逐字卡拉 OK。
- `swift test` 覆盖格式分流、原文/时间轴校验、重复歌词、说明文字、取消和分钟进位。`MINIVOICE_TEST_AI=1 swift test` 额外用系统语音生成短音频，运行实际本地模型集成验证（首次运行需下载模型）。

### 歌词显示与导入修复

- 歌词区使用浅色半透明背景（随系统深浅模式适配）、清晰当前句与淡化的上下文，取消彩色行底板；当前句居中，紧凑高度下按三行重新计算字号与行距。
- 保存/导入时去除空白行，纯文本长句优先在空格、标点等短语边界分行。已有 LRC 时间标签（包括间奏空文本标记）保留，不推测拆行时间。歌名、制作信息保存在 note 元数据中。
- AI 对齐前完整解码音频，避免流式解码提前结束造成 Broken pipe；无法完整解码的文件会显示简短提示。
- 少数匹配失败的行会根据前后已匹配时间重新分析音频片段。仍未匹配的行保留原文，保存后提示待校正行数，不虚构时间；匹配不足 65% 时提示检查歌词版本。
- 诊断日志保留在 `~/Library/Application Support/MiniVoice/LyricsAI/last-error.log`，弹窗不再显示 FFmpeg 或模型进度日志。
- Worker 回归测试：`PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s Tests/WorkerTests`。可用 `MINIVOICE_AI_FIXTURES` 指向含 path/lyrics/title/duration 的 JSON 数组，对本地音频运行只读集成验证。

- 封面裁剪与内描边共用连续圆角；歌词滚动条采用透明轨道和细滑块，避免系统白色轨道遮挡歌词卡片。

- 侧边栏、歌词和播放控制共用侧边栏磨砂材质、色调、26pt 连续圆角、描边及阴影。两处列表共用滚动组件：6pt 无轨道滑块、28pt 最短长度、同一显隐动画，按视口/内容高度比例计算滑块并支持拖动。
