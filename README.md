# MiniVoice

轻量原生 macOS 本地音乐播放器，基于 SwiftUI 与 AVFoundation，macOS 13 及以上。

## 已实现

- 在“设置 → 音乐库”配置多个文件夹，启动读取应用目录中的轻量索引；支持子目录、重叠目录去重、增量刷新、歌曲/歌手/专辑搜索。移除目录不删除文件。
- 播放 MP3、FLAC、M4A、AAC、WAV、AIFF；进度跳转、音量、上一曲/下一曲。双击歌曲开始播放，播放中选择其他歌曲立即切换。
- 文件夹、播放模式自动保存；重启读取 v2 轻量索引，恢复上次歌曲与播放进度，不自动出声。播放时每秒保存位置，暂停和拖动进度时立即保存；已播完或进度无效时从头开始。旧 `.minivoice-playlist.json` 自动迁移并保留。启动延迟检查已知文件状态，新增文件通过手动刷新发现。
- 每个目录独立保存轻量 JSON 索引（相对路径、歌曲信息、时长、文件状态和资源引用），封面与歌词分别缓存，原子写入；编辑歌曲后更新相关记录。缓存不包含音频，未改封面时保留歌曲内的原图。
- 音量和播放模式集中在播放器区域。音量使用 CoreAudio 控制当前 Mac 输出设备，并跟随系统音量与设备变化；不支持软件调音的设备会显示说明。
- 单曲播放（播完停止）、列表播放（末曲停止）、随机播放（一轮不重复且可返回历史）、单曲循环、列表循环。
- 上一曲在播放超过 3 秒时先回到开头，再按一次切换。手动上一曲/下一曲保留播放或暂停状态，顺序模式首尾可切换。
- 设置中配置红色关闭按钮行为：继续后台播放（默认）、暂停播放、退出；支持 Dock 和状态栏重新打开。恢复标准窗口标题栏和关闭/最小化/缩放按钮。
- 主窗口和桌面歌词分别记住位置，主窗口同时记住大小；关闭后重新打开及退出后重启均恢复，支持副屏。原屏幕断开时回退到可见区域。
- ⌘P 播放/暂停，⌘←/⌘→ 上一曲/下一曲；⌘Q 退出。
- 参考提供的绿色 MV 音符，以原生矢量绘制应用图标，构建时生成全尺寸 ICNS。
- 状态栏图标可选隐藏、彩色、纯色（随系统明暗外观变化），设置自动保存；可在 MiniVoice → 设置（⌘,）或状态栏菜单切换。
- 状态栏菜单支持打开主窗口、播放/暂停、上一曲/下一曲和退出。
- 编辑歌曲名称、专辑，逐个添加/移除歌手；文件内以 ` / ` 保存多个歌手，保留名称内部的 `/`（例如 AC/DC）。不同播放器对多歌手的结构化识别可能不同。
- 读取内嵌歌词与封面；没有内嵌歌词时自动读取同名 `.lrc`。
- 导入 LRC/SRT/TXT、编辑歌词，支持多时间标签与 `[offset:...]`。SRT 自动转换成 LRC 时间标签。
- 大字号逐行歌词，当前句高亮，点击歌词跳转，有时间轴的歌词始终自动跟随滚动。纯文本在编辑器保存时通过本地 AI 自动匹配歌曲并生成 LRC；同步期间显示进度并可取消，失败时可重试或仅保存原文。仍可试听并逐行手动打点。
- 为 MP3、FLAC、M4A 写入名称、歌手、专辑、歌词，以及自定义封面的添加、替换、删除；音频码流复制，不重新编码。
- 写入成功才更新界面；每次保存会在歌曲同级的 `backup/` 文件夹保留 `原文件名.minivoice-backup-UUID` 原文件备份。`backup/` 不会被音乐库扫描；需要恢复时将备份复制回原文件名。备份会累积，可在确认编辑正确后手动删除。
- 歌词写入音频文件本身的 `lyrics` 元数据字段（FLAC 为 Vorbis Comment，MP3/M4A 为各自容器标签）；没有内嵌歌词时，播放器才会读取同名 `.lrc` 文件作为显示回退。

- 正在使用的耳机断开时自动暂停，保留播放进度；重新连接后手动恢复。支持蓝牙输出及系统可识别的有线耳机，主动切换仍连接的输出设备不会触发暂停。

## 运行与部署

```sh
swift run
```

`swift run` 不组装 `.app`，需要本机提供 FFmpeg 才能使用扫描和标签编辑功能；`Scripts/build-app.sh`、`deploy.sh` 与 `build-dmg.sh` 使用仓库内置的 arm64 FFmpeg。

```sh
swift test
Scripts/deploy.sh
```

应用标识为 `com.xcosmos.MiniVoice`。新版首次启动会从 `local.fanchen.MiniVoice`（及更早的 `com.local.minivoice`）迁移设置，包括音乐文件夹、播放状态、快捷键、歌词选项和窗口位置；保留旧配置，已有新配置优先，之后不重复导入。`~/Library/Application Support/MiniVoice/` 下的本地歌词资源和音乐文件夹中的歌单缓存继续沿用。

部署脚本先构建 release、验证签名，再退出旧版并替换 `/Applications/MiniVoice.app`，最后启动。歌词编辑页并行查询网易云（优先取 YRC 逐字歌词）、QQ 音乐、酷狗音乐（优先取 KRC 逐字歌词）、LRCLIB 与偏重中文曲目的 LrcAPI，外文歌还可由 lyrics.ovh 补充纯文本；候选会标明来源、合并重复内容，并保留简体预览与应用选项（仅转换字形，不翻译粤语）。确认应用后再明确保存到本地。arm64 安装包内置仓库中固定版本的 ffmpeg/ffprobe，构建和安装不再依赖 Homebrew FFmpeg；来源、校验值和许可见 `Vendor/FFmpeg/README.md`。大型 AI 模型和 Python 依赖仍按需安装：首次启用需要 Python 3.11/3.12，并按需安装运行环境和模型；已有本地资源不会删除。

单独构建：`Scripts/build-app.sh [debug|release]`，产物在 `.build/MiniVoice.app`。

当前版本为 **2.3.0**（构建号 8）。制作拖拽安装包：`Scripts/build-dmg.sh`，自动构建 release 并生成 `.build/dist/MiniVoice-2.3.0-arm64.dmg`（文件名按实际版本和架构生成）。如已构建，可使用 `Scripts/build-dmg.sh --skip-build`。打开 DMG 后，将 MiniVoice 拖入右侧 Applications 文件夹即可安装；首次保存安装布局需要 Finder 自动化，后续可用 `--reuse-layout` 无界面复用同版本布局，或用 `--layout-from /absolute/path/previous.dmg` 复用旧版本布局。安装包沿用当前 ad-hoc 签名，尚未进行开发者签名与公证；其他 Mac 的元数据编辑仍需安装 FFmpeg。

## 当前边界

### 分层缓存（v2）

音乐文件是数据源，不使用数据库，也不复制音频。所有可重建缓存统一保存在 `~/Library/Caches/com.xcosmos.MiniVoice/`；所有音乐目录的轻量 JSON 索引合并在单个 `LibraryIndex/library.json` 文件中，各目录记录独立更新，只包含基本信息、稳定路径标识、音频与外部歌词文件状态、资源引用。96px 列表缩略图、512px 分类页封面、最多 1024px 详情封面和歌词文本放在 `Resources-v2/`，封面复制与拖拽文件放在 `Exports/Artwork/`。设置的音乐库页面可打开统一缓存文件夹；启动会迁移并合并旧索引及旧应用标识的资源，冲突文件保存在同目录的 `MigrationBackup/`。旧 `.minivoice-playlist.json` 首次加载时后台迁移并保留原文件；旧缩略图不会冒充高清详情图。

扫描或启动恢复索引时同步准备分类页高清封面并保存本地缓存；压缩图片在内存中就绪，分类卡片首次出现即可同步显示。歌曲列表预加载可见行附近的 96px 封面；命中内存的封面在首帧同步显示，不再等待异步回调。列表图片缓存按像素成本限制为 64 MiB，超大歌单额外预加载当前行附近的封面；缺失封面重建使用独立处理流程，不堵塞普通缩略图读取。详情只保留当前浏览、播放及最近请求所需的少量资源，编辑页另读源文件原图，音频和完整歌词不因封面预加载而全部读入内存。手动刷新按文件大小、修改时间和外部歌词状态增量读取；启动后延迟检查已有歌曲的变化，暂时不可访问的源文件不被自动删除。新增文件仍通过手动刷新发现。

缓存写入串行化、原子替换，编辑只更新对应目录索引及相关资源，删除缓存记录在后台进行。资源被清理后按需重建，失败短期降频重试。启动后后台将可淘汰派生资源缓存控制在约 300 MiB，优先清理较旧资源；分类页高清缓存由扫描按当前歌曲引用清理，避免滚动时重新提取。用户配置、收藏、歌单、音频、外部歌词和编辑备份不参与清理。

- AAC、WAV、AIFF 支持播放，暂不提供完整标签/封面写入，编辑窗口会明确提示。
- 暂无封面裁剪、自定义播放列表排序、系统媒体键接入。
- 歌曲信息编辑页支持在线查找高清专辑封面：并行查询 Apple Music、网易云、QQ 音乐与酷狗音乐，预览大尺寸图片并显示实际像素；选择后仅更新编辑页，点击“保存”才写入音频文件。封面清晰度取决于来源图片。
- 外语歌词支持译文显示：在线候选标明“含译文”，网易云、QQ 音乐与酷狗返回的译文可随原文一并保存。播放器提供“译文”开关，在原文下方同步显示，桌面歌词也可显示译文；无译文时可在歌曲信息页手动填写带时间标签的译文。
- 歌词自动选择逐字、逐行或普通文本展示：支持 Enhanced LRC 的 `<mm:ss.xxx>` 标签及 YRC 时间片段；无效逐字数据按行降级。真实逐字歌词按原始时间高亮；逐行歌词在主播放器、桌面歌词和在线预览中使用仅供显示的估算逐字扫描，不写入歌词文件、不改变来源类型；纯文本不估算。在线候选标明类型，支持 LRCLIB Lyricsfile 逐字数据，并可拖动预览时间轴；应用、保存和整体偏移保留原始逐字标签。支持 QQ 原生 QRC、网易云 YRC、酷狗 KRC 及 AMLL 原生 TTML 逐字时间。具体可用性取决于歌曲版本与服务响应。
- 目录内容变化后点“重新扫描”更新隐藏歌单；启动不自动遍历音频。目录移动后需重新配置，缓存内使用相对路径。歌词推荐 UTF-8。
- 旧版逐文件导入已移除；首次升级需在设置里添加音乐文件夹。
- 本机使用 ad-hoc 签名；向其他 Mac 正式分发还需处理开发者签名、公证与 FFmpeg 许可要求。当前内置 FFmpeg 仅支持 arm64。

音乐墙样式可在设置的“播放器样式”中选择，也可点击侧栏的应用图标循环切换。封面以大小交错的拼贴铺满窗口，支持鼠标四向拖拽、触控板双向滚动和双指捏合等比缩放。单击卡片在墙面内展开并居中，周围封面同步让位；双击聚焦并播放。底部玻璃播放条固定显示，右上角搜索图标在悬浮时展开，鼠标移出恢复圆形。侧栏沿用音乐库尺寸，宽窗口可保持展开，窄窗口覆盖墙面并可点击外部收起。macOS 26 及以上使用原生液态玻璃，旧系统使用毛玻璃兼容效果。

## 验证

`swift test` 包含缓存启动不扫描、损坏缓存重建、SRT/LRC 识别、原始封面保留、文件夹递归/去重/移除安全、播放模式边界、随机历史、实际播放结束自动切歌及停止，以及 MP3/FLAC/M4A 文件往返测试：中文标签、多歌手、歌词、封面添加和删除、备份、AVAudioPlayer 可读取，以及保存前后音频码流 SHA-256 一致。

## AI 歌词自动跟随

在“编辑歌曲信息”粘贴纯文本、LRC 或 SRT 后保存。完整时间标签直接使用；缺少时间标签时，后台进程读取当前歌曲音频，使用 [stable-ts](https://github.com/jianfch/stable-ts) + Whisper small 在本机生成逐行时间轴。首次使用自动建立独立 Python 环境并下载依赖和约 461 MiB 模型；之后可离线使用，无需 API Key，歌曲和歌词不上传。结果按编辑器选择保存到文件标签、`lrc/` 或两者，并更新歌单缓存。拖动进度和桌面歌词复用同一时间轴。

- AI 文件位于 `~/Library/Application Support/MiniVoice/LyricsAI/`；使用 Homebrew Python 3.11/3.12 或本机 Xcode Python 3.9，以及现有 FFmpeg。
- 歌名、常见作词/作曲等信息和段落标记保存在 LRC 的 `[note:...]` 元数据中，不参与演唱对齐。歌词正文保留输入顺序和重复段落；已有手动时间点保留，时间冲突时会提示。
- 处理时编辑窗口保持打开，取消后保留输入。只有对齐成功后才写文件；失败可选“仅保存原歌词”。仅保存的纯文本不会自动滚动，可再次打开编辑器保存重试。
- 应输入完整、与当前音频版本一致的歌词。复杂伴奏、现场版、漏句或副歌省略可能导致失败或偏移；可手动打点校正。本地 AI 匹配生成逐行时间轴；已有有效逐字时间片段会保留。
- `swift test` 覆盖格式分流、原文/时间轴校验、重复歌词、说明文字、取消和分钟进位。`MINIVOICE_TEST_AI=1 swift test` 额外用系统语音生成短音频，运行实际本地模型集成验证（首次运行需下载模型）。

### 歌词显示与导入修复

- 歌词区使用浅色半透明背景（随系统深浅模式适配）、清晰当前句与淡化的上下文，取消彩色行底板；当前句居中，紧凑高度下按三行重新计算字号与行距。
- 保存/导入时去除空白行，纯文本长句优先在空格、标点等短语边界分行。已有 LRC 时间标签（包括间奏空文本标记）保留，不推测拆行时间。歌名、制作信息保存在 note 元数据中。
- AI 对齐前完整解码音频，避免流式解码提前结束造成 Broken pipe；无法完整解码的文件会显示简短提示。
- 少数匹配失败的行会根据前后已匹配时间重新分析音频片段。仍未匹配的行保留原文，保存后提示待校正行数，不虚构时间；匹配不足 65% 时提示检查歌词版本。
- 诊断日志保留在 `~/Library/Application Support/MiniVoice/LyricsAI/last-error.log`，弹窗不再显示 FFmpeg 或模型进度日志。
- Worker 回归测试：`PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s Tests/WorkerTests`。可用 `MINIVOICE_AI_FIXTURES` 指向含 path/lyrics/title/duration 的 JSON 数组，对本地音频运行只读集成验证。

- 封面裁剪与内描边共用连续圆角；歌词滚动条采用透明轨道和细滑块，避免系统白色轨道遮挡歌词卡片。

- 侧边栏、歌词和播放控制共用侧边栏磨砂材质、色调、26pt 连续圆角、描边及阴影。两处列表共用滚动组件：6pt 无轨道滑块、28pt 最短长度、同一显隐动画，按视口/内容高度比例计算滑块并支持拖动。

### 设置页面

- 采用侧栏分类导航：通用、音乐库、歌词匹配、快捷键。设置即时保存。输出设备在播放器的设备弹出面板中选择；在线歌词在歌曲信息编辑页查询。
- 所有页面共用分组卡片、设置行、系统按钮和统一间距，内容较长时可滚动查看，支持系统深浅外观。
- 音乐库显示文件夹名称与路径、空状态、扫描状态和可展开的问题列表；歌词资源逐项显示下载状态，删除前确认。
- 切换离开快捷键页面时取消未完成的录制。

### 播放器样式与分类浏览

- 设置 → 通用 → 外观 → 播放器样式，可即时切换“简易样式”和“音乐库样式”，选择自动保存。未设置时保留原有简易样式。也可点击左上角应用图标切换，显示窗口碎片过渡动画；减少动态效果时使用简化过渡。
- 音乐库样式左侧仅放导航：音乐库、最近播放、收藏、歌手、专辑和自定义歌单。歌曲列表移到右侧上方，搜索位于右上角；左上角始终保留侧栏切换按钮。
- 点击底部播放器的专辑封面，右侧列表带动画切换为当前播放歌曲的歌词，再次点击同一封面可收起；悬浮以向上浮起/向下收回及方向箭头提示动作，不显示文字工具提示；右上角显示编辑歌曲信息与歌词按钮，以及向下收起按钮。收起后返回原分类、搜索与列表，不中断播放。
- 点击歌曲旁的爱心收藏；右键歌曲可加入歌单。在侧栏新建歌单，右键歌单重命名或删除；歌单内可右键移除歌曲。收藏和歌单独立保存，不修改音频标签，也不会因为删除歌单而删除歌曲文件。
- 歌手与专辑按现有标签分组，点击卡片进入歌曲列表。歌曲关联使用文件路径，缓存重建后仍可关联；音乐文件移动或改名后需要重新加入收藏/歌单。
- 分类卡片独立读取最多 512px 封面，不放大 96px 列表缩略图；进入分类详情时重置歌曲列表位置，返回时恢复分类页及滚动位置，名称空白处理与分组保持一致。原始图片本身低清时无法凭空增加细节。
- 歌手分类按姓名／歌曲数量排序，专辑分类按专辑名／歌曲数量排序，分类各自保存排序方向。歌曲列表支持源文件添加时间（添加到目录的时间，缺失时使用创建时间）、源文件修改时间、歌曲名、歌手名和专辑名排序；分类详情隐藏与当前分类重复的排序项。
- 多选时提供当前列表全选／取消全选及已选数量；单击多选不经过双击识别，未改变的歌曲行跳过重绘，完整封面缓存编码放在后台。
- 音乐库样式与简易样式共用左上角品牌区（图标、名称、副标题和后台任务提示），侧栏浮层出现时提供收起按钮。移除侧栏底部设置入口，仍可通过菜单或 ⌘, 打开设置。
- 音乐库标题和歌曲数量同一行，工具栏采用紧凑高度；歌曲列表按可用空间依次展示：歌名和歌手上下两行、歌名和歌手双列、专辑、播放时长，以及编辑按钮；收藏与编辑操作位于右侧。缩放窗口时列宽和透明度连续跟随可用宽度变化。移除滚动表头，滚动条靠右并预留空间以避免裁切封面；长文本尾部省略，悬浮显示完整名称。
- 播放进度与音量使用自定义滑块，支持点击、拖动和左右方向键；macOS 26 显示玻璃滑块，旧系统使用材质回退。

### 图标资源

应用图标固定保存在 `AppBundle/MiniVoice.icns`，打包直接复制，不再每次编译图标生成器或生成 iconset。修改 `BrandIcon.swift` 后，显式运行 `Scripts/generate-icon.sh` 更新应用图标。菜单栏和设置页的小图标仍由 `BrandIcon` 绘制。

### 可再生构建文件

`.build/` 内的编译缓存、预览程序、日志和 DMG 均不属于源码。清理会释放空间，但编译缓存删除后下次构建需要重新编译；`offline-ai` 中的本地 AI 资源删除后可能需要重新下载。`Docs` 中的采样文件是性能报告的依据，建议保留。
