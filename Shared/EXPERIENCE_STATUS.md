# 体验版：自有组件替换现状

以后产品讨论使用“体验版”。现有 Mac-debug 文件名、独立标识暂不变化，用于和正式版隔离；Android 当前默认入口已进入自有界面。

| 平台 | 实际接入 | 主要剩余工作 |
| --- | --- | --- |
| Android 手机/平板体验版 | 三种样式、导航、列表/歌词/队列、按钮、选择器、滑块、滚动条、弹窗、设置；真实音乐库/播放（底层标签写入与恢复代码保留，按当前范围暂不展示歌曲编辑入口） | 真机材质与连续触控稳定性；Android 在线歌词/封面搜索、AI 匹配尚未与 Mac 对齐；特殊格式限制 |
| Mac 体验版（MiniVoice-debug） | 桌面三种样式与键鼠逻辑；自有设置、编辑器、桌面歌词、关于；封面/歌词搜索、打点、真实后台保存 | 更多实体窗口尺寸、交互和材质验收；原正式版仍保留原生辅助窗口，不代表体验版未接入 |

| 鸿蒙 | 尚未接入宿主 | Web 内容容器、音频/文件/权限/媒体控制适配及系统兼容验证 |

## 复用边界

自有内容组件是应用维护的 React/CSS/SVG 代码，按钮热区、状态、图标、选择、拖动、动画、焦点和返回规则由应用控制，不是 Android View 或 SwiftUI 控件换皮。它们运行在 Android WebView、Mac Electron 的内容容器中；未来可在适当的其他平台 Web 容器复用。

可以复用组件、主题、动画和大部分业务状态逻辑，但不是把安装包直接复制到其他系统。平台适配仍要提供音频、文件授权/读写、媒体通知、键盘/鼠标/触控、窗口与安全区域。IME/辅助功能和系统授权页面保留系统能力。

## 本轮视频问题与搜索动画

视频显示音乐墙在切换/拖动焦点卡片时出现大片空白。原可见区域查询依赖未重排的封面坐标；现在先对卡片重排坐标做逆变换，并覆盖过渡前后的范围，再查询空间索引。测试以 4/100/1037 首、三种缩放和多个平移位置，逐张验证实际屏幕内封面不被错误裁掉。实体手机视频同场景仍需要回验，不据数学测试保证所有 GPU 问题已消失。

搜索控件改为持续存在的单一材质容器，从圆形向左展开成长条；输入、图标和关闭按钮配合淡入，关闭回到圆形。保留查询、空查询点外收起、Esc、焦点和减弱动态效果。底部播放条的圆形/长条交互保留。

验证见 .build/work/shared-core/experience-search-*。未使用没有依据的百分比宣称整体迁移完成。

## 连续切卡补充修复

Android 音乐墙接替未结束的聚焦动画时，保留实际已绘制的封面节点和中间几何，而不只保留目标布局查询到的节点。聚焦材质叠在原已解码封面之上，不再新增一张过渡封面图；墙封面关闭通用按钮缩放，几何由画布管理。播放条圆形和展开态统一锚定左下，横屏焦点区域避让左侧播放条。主题只在设置中切换，移动侧栏主题按钮移除；Mac 侧栏已无该入口。

这解决已复现的节点交接缺口，不代表已证明所有 Android GPU 闪屏原因都消失。证据见 wall-flash-* 报告，真实手机录屏场景仍需回验。
