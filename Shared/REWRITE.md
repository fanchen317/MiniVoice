# 当前实施：重写 Mac 与 Android

先完成这两个实际产品，再考虑 iOS 和 Windows。其他平台现有代码保留，但不在当前重写中增加宿主或适配。共用模块允许未来扩展，不为了未来平台提前增加产品分支。

## 验收基准

- Android：现有手机和平板页面、三种样式、触控操作与横竖屏体验。
- Mac：现有桌面页面、三种样式、窗口变化、键鼠和快捷键体验。
- 使用 MiniVoice 自有内容控件和业务规则；平台层仅承担文件权限、音频、系统媒体控制和运行容器。
- 不能通过统一成一个页面、删除功能或只接通数据宣布重写完成。
