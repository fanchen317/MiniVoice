# MiniVoice 自有组件标准

规范性规则见 [组件契约 v1](../../Docs/COMPONENT_STANDARD.md)。以下为具体实现与历史迁移说明；不得将历史记录视为全量验收结论。

## 当前重写范围

当前只重写 macOS 和 Android。以各自现有页面设计与操控逻辑为验收基准，使用 MiniVoice 自有组件重建应用界面，并共用业务规则。先完成两端的功能、交互与稳定性验收，再考虑 iOS、Windows；鸿蒙、Linux 同样不属于本轮实施范围。保留已有其他平台代码，不继续扩展其适配，也不将抽象接口视作平台实现。

## 产品边界

移动端包含手机和平板，以现有 Android 页面设计和操控逻辑为参照，主输入为触控；桌面端包含电脑，以现有 Mac 页面设计和操控逻辑为参照，主输入为键鼠。primaryInput 记录产品主输入，桌面 input 继续记录当前鼠标/键盘焦点模式，两者不混用。操作系统、窗口宽度、横竖屏不能互相替代：宽平板仍是移动端，窄电脑窗口仍是桌面端。本轮移动端宿主为 Android，桌面宿主为 macOS；其他平台只保留未来扩展可能。

共用的是组件语义、状态规则、数据协议、几何和可复用行为。两端的布局、密度、动画和输入反馈保留各自基准。系统负责音频、授权选择器、通知和媒体会话等平台能力；应用内容控件由 MiniVoice 渲染。使用 WebView/DOM 的语义元素不等于使用 Android View 或 AppKit 内容控件；运行容器和系统服务仍需宿主。

## 实现约束

1. 业务组件通过宿主适配器调用能力，不依赖 Java/Swift 类型。
2. 深浅色和材质由应用的视觉变量决定，不随系统原生控件默认主题漂移。
3. 图标视觉尺寸可以小于触控区域；不得以缩小可点区域解决布局问题。
4. 导航、排序、搜索、滚动锚点、展开和墙相机属于页面状态，弹窗焦点恢复不能改变页面位置。
5. Escape/系统返回逐层关闭；桌面播放快捷键不能穿透弹窗。Tab 必须覆盖按钮、输入框、复选框和操作链接；普通按键必须能到达自绘滑块等内容控件。
6. 平板布局通过可用空间调整，保持触控操作和移动端导航规则。键鼠支持可作为辅助能力，不能将平板自动换成桌面家族。
7. 新组件需验证真实交互与状态，不通过删除原功能缩小复刻范围。

## 后续迁移范围

侧边栏、上下文菜单、列表/网格、拖拽滚动条、播放栏、歌词和音乐墙仍需逐项收敛到组件边界；音乐墙的缩放分级和液态材质也尚未完整对齐。原 Android 默认播放器仍保留，跨平台界面仍处于试用阶段。iOS/鸿蒙共享界面宿主尚未接入。

## 组件交互验证

`bash Scripts/tests/test-desktop-components.sh` 启动独立的本地组件测试页并在 Electron 中发送鼠标和键盘事件，结束自动清理服务器。测试页是合成数据，不连接真实音乐库，也不被生产 Vite 入口打包。覆盖菜单边缘、禁用项、焦点/键盘选择，进度拖动与轮询，以及 Choice/CheckControl。它是组件集成测试，不等于完整 Mac 播放器所有页面已经完成实际 UI 验收。Android 的真实长按、滑动取消、歌单和播放行为由 instrumentation 验证。

## 按样式修正（2026-10-23）

手机共享 PlayerControls 的图标改为应用源码内 24×24 SVG 路径；不加载系统符号或 PNG 遮罩，不使用 mask-size 放大裁切。音乐墙设置使用专属滑杆图形。按钮重置浏览器默认 padding，图标不拦截指针。桌面旧页面仍有已打包符号资源，本次没有宣称全桌面图标迁移完毕。

音乐墙卡片采用封面到内容的交叠过渡；退出同样保留封面直到墙位置恢复。Artwork memo 避免相机每帧触发图片组件重绘；聚焦的额外可见范围从 700px 缩至 220px，小型播放按钮不继承高斯模糊。播放、上一首、下一首、收藏、展开拥有稳定网格槽位，预览不会挤走播放按钮。

侧边栏进入独立覆盖层，按 safe inset 限制高度；标题区明确分配图标/文字/操作槽。简易样式保持原版两入口（音乐库、最近播放）、歌曲总数与目录工具、76px 歌曲行、52px 封面、歌手副标题；不显示完整导航与歌单区，切换两入口保留抽屉。音乐库/音乐墙继续使用完整导航。

侧边栏背景进一步使用 DrawerMaterial：音乐墙取当前墙面封面的位置快照，简易/音乐库使用当前歌曲封面场景，应用自己的模糊层与深浅色罩层合成。它不再使用 WebView 的嵌套 backdrop readback；打开期间背景取样冻结，内容继续交互。不是完整 DOM 截图或完整液态折射。移除整页 filter blur 与小按钮重复 backdrop，避免 Android 白块/不重绘。

Android 宿主只在样式、主题、方向、沉浸状态改变时重新设置窗口。普通滚动/墙相机持久化不再反复执行窗口布局和系统栏配置。

### Android 音乐墙 v4

样式入口是 `.mv-brand-logo`，顺序简易 → 音乐库 → 音乐墙；切换保留抽屉，提示图形由 App SVG 绘制。`styleTransition.js` 提供切换生命周期，禁止在 View Transition 更新回调内等待 RAF（捕获期间 RAF 可能暂停而超时）。

墙相机与聚焦/展开进度通过 refs 和合帧绘制，组件状态只用于边界与最终提交；聚焦相机被拖动打断后不再接管手动位置，几何继续完成。原封面保持挂载，内部歌词按目标尺寸布局；播放控件首槽固定左下。首次恢复与主动定位是两条明确路径。

所有内容 JSX 的操作按钮现经 ActionButton，原生 button 仅存在于该基础组件内部。保留 HTML 输入与文本编辑语义以支持 IME/辅助功能，视觉由应用样式绘制；没有原生 select/range/checkbox/number 页面控件。NumberField 提供自绘加减、十进制草稿与方向键步进。useSurfaceMotion 共用弹窗/浮层进入退出与减弱动态效果规则；布局不随进入缩放重新测量。移动 Modal 与桌面 Modal 使用各自布局，底层行为共用。

SearchControl 是持续存在的自有材质容器，圆形与长条之间通过宽度和圆角过渡，内容渐入；共享给移动设备家族，遵守减弱动态效果、焦点与空查询点外收起规则。体验版跨平台进度见 Shared/EXPERIENCE_STATUS.md。

### Disclosure 自有折叠区

`data-mv-component="disclosure"` 替换设置重复候选、扫描问题、任务问题与歌词打点的浏览器 details/summary。参数为 title、children、className、disabled；展开状态由组件局部持有，默认收起、卸载重置，无业务或持久化事件。ActionButton 提供鼠标、触控、Enter/Space、焦点环、禁用语义和 aria-expanded/controls；收起使用 hidden，子内容保留挂载以保存草稿，隐藏子项退出焦点序列。Esc/系统返回仍归属外层面板，不额外消费。

复用各样式/主题的正文颜色，桌面标题命中高度至少 28px、触控至少 44px，使用应用 chevronDown 图标；只旋转图标，连续切换跟随最新展开值，减弱动态效果关闭旋转过渡，内容立即进入真实布局。组件测试验证键盘开合、草稿保留、禁用；实际页面与平台验证以验收台账为准。

### 2026-10-23 用户录屏闪屏与按钮比例整改

桌面 Icon 的 `.glyph.app-drawn` 使用 `--mv-icon-size`，默认 20px，不再继承旧位图外框的全幅尺寸。主播放 24px、音量 18px、品牌切换提示 10px、搜索清除 13px；搜索符号退出旧绝对定位，图标实际居中。简易/音乐库工具按钮统一 32px 点击区，常用播放副控件 36px，顶部工具 38px；音乐墙收起播放条保持原根材质，圆形外径与三个工具同为 38px，内层播放按钮 36px 透明背景，取消白色套圆。持续根、idle 状态所有者、悬浮/键盘/触控规则不变。侧栏图标去除胶片孔，输出设备图标缩至自有绘制框。

Android Wall 不再把全部封面放在 `will-change:transform` + translate3d/scale 的公共世界合成层上：保留原相机、重排、可见区与手势规则，每帧将可见卡片投影到视口 left/top/width/height。标题字号随相机比例变化，已加载封面与打断过渡仍保留。画布与聚焦内容使用 overflow:clip，焦点不能通过隐藏滚动偏移画布。此改动处理整墙栅格化和隐式滚动的风险，不宣称已定位用户手机的唯一 GPU 根因。

新增验证：1037 首合成曲库 12 次连续切卡的实际画面背景占比采样、画布无公共提升变换、焦点不改变画布滚动；Android WebView 通过 UiAutomation 截图执行同类采样。采样能发现整墙大面积消失，不能发现所有单帧闪烁，也不等于实体手机录屏通过。桌面验证收起按钮与工具直径、简单/音乐库窄窗实际样式和 SVG 尺寸，截图人工检查。

### 2026-10-26 手机滑动 / Mac 播放栏续修

手机 Wall 保留独立卡片与不可滚动画布，每帧仅改变各卡片的二维平移；尺寸相同时跳过 width/height 写入，比例未变时不更新继承字号变量。每卡使用 layout/paint/style containment 隔离布局；不重新引入整个世界平面公共提升层。相机/重排/打断状态所有者不变。合成 1037 曲库同一 60 步拖动 CDP 数据：修改前 LayoutCount=125，修改后=23；原始数据 mobile-pan-before.json / mobile-pan-after.json，代表本机 Chromium 单次同条件诊断，不是 Android 实机 FPS 或流畅度结论。

Mac 音乐墙采用正式 Mac 参考薄玻璃皮肤：正文位于前景、背景采样与边缘折射位于 ::before；与移动端基础高斯材质明确区分。Player 的 idle 仍归 useIdleCollapse；wallDock.css 管理持续根的宽、高、内边距、播放按钮尺寸和渐隐内容，使用 .42/.88 对应的原版弹簧参数。内容保留展开时几何，通过裁切/透明度交接，折叠即 inert，不再即时清零子内容宽度。悬浮、键盘焦点、忙碌弹层、连续打断和减弱动态继续遵循原规则。保留用户之前要求的左下锚点、38px 收起圆和三秒空闲规则；不恢复旧版底部居中布局。

### 2026-10-26 自有交互动画与触觉反馈

视觉仍全部由自有组件、应用 SVG、CSS/WAAPI 和自有过渡模型绘制。系统不提供内容按钮/侧栏/弹窗样式；ViewTransition 仅作为快照机制，进入/离开关键帧由应用定义，Mac 样式切换仍由自有碎片画布及降级过渡绘制。手机震动是用户明确要求的系统能力边界。

ActionButton 新增 haptic（默认 true），通过 FeedbackContext 获取页面注入的回调；仅可信、有效点击触发，不绑定平台、网络或持久化，不等待回调、不因其失败阻断业务。禁用/busy/程序性 click 不反馈。Wall 自管 pointerup 激活，卡片关闭 ActionButton 的触觉，由唯一 activate 路径触发，避免双次反馈；滑动取消不激活。Android 适配器桥接 haptic() 到主线程 WebView.performHapticFeedback(CONTEXT_CLICK)，45ms 去重，尊重系统触感设置，不使用强制忽略标记，也不进入播放/读写任务队列。模拟器可验证调用链，不能验证实体震感。

DrawerLayer（data-mv-component=drawer-layer，data-surface-exit=drawer 标记退出副本）复用 useSurfaceMotion：展开从左侧小位移/透明度进入，退出保留不可交互的图层，重开清理旧副本。useSurfaceMotion 的 modal/drawer/popover 分型由调用方传入；保持最终几何，动画只作用于渲染层，关闭从当前视觉状态退出，保留主题变量，退出层继承原 z-index，避免侧栏退场遮住新设置页。副本 inert/aria-hidden，无角色与重复 id，超时/动画结束清理；减弱动态时直接终态，并响应运行时偏好变化。

点按反馈触控 .95、桌面精确指针 hover 及已有 Mac 皮肤分别提供；品牌按钮使用专用反馈（不叠加通用缩放），图标小角度倾斜，减弱动态取消。Mac 侧栏使用既有 chrome 弹簧进入/退出。移动样式切换保留最新连续点击意图，不再因过渡中直接丢弃；Mac 排队保留最新回调。播放轮廓为独立、不拦截指针的边缘层；手机区分播放更亮/暂停减弱，Mac 保留当前播放曲目轮廓。进入只短提示，不做无限 GPU 光晕。

验证：实际鼠标/触控反馈回调计数与 busy 抑制；移动侧栏/设置进入中间态、关闭 inert 副本、快速重开与最终清理；原有焦点、返回、动画打断、布局/三样式深浅主题及 Android portable。实际结果见验收台账。

Wall 新增 playing（默认 false），由页面快照控制轮廓强度，不持有或改变播放业务状态。FeedbackContext 只提供注入，不产生 DOM，无单独绘制标记；DrawerLayer 的 children 与根事件由页面传入，局部动画在卸载时清理。

### Mac 展开居中与配置按钮避让（用户最新纠正）

Mac 播放栏收起圆保持左下 18px，展开中心为 (窗口宽 + 可用墙面左侧预留)/2；由 wallDockPlacement 计算目标 left，持续根按同一弹簧过渡 left、宽高与内边距。配置按钮默认底距 18px，仅当展开播放栏右边缘加 12px 安全间距越过配置按钮左边缘时上移至 94px。收起时取消避让。弹出设置面板复用同一 --wall-tools-bottom，避免按钮与面板锚点不一致。此处覆盖此前固定左下展开的 Mac 规则，Android 布局不变。

### 手机状态栏 / 导航栏与弹窗拖动条

Android 三样式统一边到边宿主：窗口不自行 fitsSystemWindows，由宿主持续发布 systemBars/cutout 的四边 CSS inset；音乐库/简易分别在页面 padding 加一次 inset，音乐墙继续由自身工具/播放条消费 inset。API 29 底部使用 system/stable inset 的较小值，避免软键盘高度被误当导航栏再次扣除。侧栏和弹窗的安全区留白同源；平板居中弹窗也加安全区。主题同时决定系统栏图标明暗。

Modal 顶部 grip 改为 ActionButton，自有标记 sheet-handle，视觉条 34×4px，命中区 44px 高、全内容宽；键盘/点按可关闭，触控拖动由 useSheetDrag 管理，正文不接该手势。只在按住时保留指针 id/起点/速度，window 捕获 move/up/cancel 可跟随移动中的句柄；每帧仅更新 panel.translate，不经过 React 重渲染。短拉/上拉/取消回弹，足够距离或向下甩动调用页面 onClose 一次；业务若保留面板则回弹。捕获丢失、失焦、旋转和卸载清理手势与动画；句柄关闭通用缩放和触觉，避免拖动时重复震动。关闭仍走页面现有确认规则，不能绕过草稿保护。

- 页面状态：播放身份来自宿主 snapshot；换曲后仅在聚焦原播放歌曲或展开卡片时跟随新歌，主动浏览其他预览卡片不强制跳走。切入音乐库主动进入全部歌曲列表并触发当前歌定位，不继承其他样式的 player/lyrics 展开状态。歌词解析结果同时绑定歌曲 ID 和原始歌词，换歌时不短暂露出上一首译文入口；仅非空译文显示开关。
