# 共享界面复刻标准

手机参考当前 Android 正式主界面；电脑参考当前 Mac 页面。各自保持原有布局关系、按钮图标、材质、主要操作和导航行为。共用核心与业务协议，界面按设备类型分开；手机横屏仍使用手机交互规范。不同系统字体、键盘、系统状态栏和授权页面允许遵循平台标准；不能据此宣称逐像素完全相同。

| 项目 | 本轮状态 |
| --- | --- |
| 简易播放页 | 横向封面信息、歌词卡片、底部播放栏；宽屏左右分栏 |
| 音乐库 | 列表、收藏、时长、选中高亮、动态音柱、定位、排序、播放展开 |
| 歌手/专辑 | 封面网格、进入返回、独立锚点和像素偏移恢复 |
| 音乐墙 | 可拖动/缩放的重复封面画布，按可见区域渲染；聚焦播放卡片、歌词展开 |
| 侧边栏 | 原图标与应用图标、导航、我的歌单、简易样式内嵌歌曲目录；背景 scene 显式模糊 |

## 尚未达到完全复刻的部分

- 文件夹授权、扫描、诊断、缓存统计/清理、文件可用性检查与歌手归并均进入自有设置。
- 批量选择与集合操作、歌单管理、歌曲信息及歌词详情已迁移；元数据写入编辑和部分深层歌曲操作尚待迁移。
- 音乐墙的原生液态玻璃折射和全部缩放过渡仍需真机逐项比对，现阶段是共享材质实现，不保证与每个 GPU 逐像素相同。
- iOS 已接共享核心，尚未接共享 WebView 宿主；其他平台也需要各自实现音频与目录权限适配。

因此入口继续保持“跨平台界面试用”，未替换默认主界面。后续按此清单收敛到完整复刻，不能通过删去原功能来宣布完成。

`Scripts/test-android-ui.sh` 的 portable 阶段覆盖真实 WAV 播放、真实本地封面解码、收藏落盘、队列、五种模式映射、三种样式 × 深浅模式截图、隐藏/重开列表锚点、歌手网格进入返回与重开恢复、音乐墙缩放/聚焦。截图中音乐库为合成测试数据，不使用用户音乐。

`node --test Shared/UI/test/*.test.mjs` 验证导航规则、长整数 ID、收藏/最近/歌单过滤、墙可见区域、串行状态写入与宿主桥接。桌面 Swift 和 Vite 构建、现有桌面测试单独验证。

## 设备类型基准（2026-10-22 更新）

- **电脑端**以现有 Mac 页面为准，包括窄窗口；Electron 的桌面预览直接复用 Mac App 组件，不加载手机 PortablePlayer/CSS。Windows/Linux 后续沿用电脑基准。
- **手机端**以现有手机页面为准，Android、iOS、鸿蒙使用触控/抽屉/底部卡片的交互规范；横屏或平板的宽度变化不改变设备类型。当前已接入 Android，iOS/鸿蒙宿主尚未接入。
- 两端共享核心与数据协议、可共享的逻辑；布局、导航和输入交互按设备类型分开，不以同一套手机 UI 强行覆盖电脑。

本轮手机端新增：歌曲长按菜单、批量选择/收藏/加入与移出歌单，歌单重命名/删除，名称变更时迁移查询/锚点/展开状态，歌曲信息与解析后的歌词详情。设置中已接入授权目录列表、系统选择目录、递归扫描、重新扫描、清空最近播放、诊断导出入口。缓存管理、音乐库检查及更深的设置仍保留原设置入口；元数据写入编辑仍待迁移。

共享设置里的重新扫描只出现在设置内。歌单删除、移除歌曲只更改集合引用；音乐文件保留。批量写入先验证全部歌曲与目标歌单，未知 ID 会整批拒绝。

## 音乐墙几何与墙内聚焦修正

共享手机界面去掉固定尺寸网格，使用原桌面/Android 一致的加权递归拼墙和周期重复实例。几何函数移入共享模块，桌面重导出同一实现，桌面页面不变。聚焦卡片在墙内占据方形空间，邻近封面按公共边界让位；相机用 520ms 过渡居中，手势可中断。播放内容以屏幕像素排版，墙缩放不会同步缩小歌词字号；歌词展开使用墙视口。歌词居中改为计算滚动容器与当前行之间的相对位置，避免嵌套卡片坐标造成裁切。

音乐墙已补充紧凑卡片分级；完整液态折射仍需真机继续对齐。拖动已加入 420ms 惯性衰减，单击仅聚焦、双击或播放按钮播放，缩放范围与原手机端一致为 60%～120%。新增几何测试与实际 WebView 中的加权尺寸、墙内聚焦、歌词可见范围检查。

## 音乐墙整版重构（2026-10-22）

手机共享页面将音乐墙从普通页头/页脚布局中拆出：墙面覆盖完整视口，浮动侧栏/搜索按钮和原音乐墙设置图标，设置内包含 60%～120% 比例、排序、播放模式、相机复位和应用设置。聚焦卡片独立按屏幕尺寸排版，紧凑与普通卡片保留 3/5 行歌词窗口；当前双语行优先分配高度，展开独立铺满视口。单击聚焦、双击播放、拖动惯性、双指缩放、周期副本定位与相机恢复分别管理。底部播放条闲置后收为仪表条。

`bash Scripts/test-wall-version.sh` 使用生产手机 PortablePlayer 和实际 Mac App，合成音乐库不接触用户文件；覆盖手机 60/100/120 比例、歌词边界、全屏展开、横屏、平板两方向、重开相机恢复，以及 Mac 实际页面全窗口、设置、聚焦、展开返回和浅色。测试截图与日志在 `.build/Shared/Core/wall-v2-*`。这套测试补充真实 Android 宿主测试，不代表全部原版功能已迁移或所有 GPU 材质一致。

2026-10-23：手机共享控件使用 App 内 SVG 图标，音乐墙聚焦保留封面交叠、稳定播放槽位；简易侧栏恢复原版两入口和目录行。抽屉背景采用 DrawerMaterial 自有取样合成，避免 WebView 嵌套模糊读回；音乐墙含玻璃高光与深浅罩层，尚非完整光学折射。Android 普通页面状态保存不再重设窗口。

## 2026-10-23 自有内容组件接入

- Mac-debug 默认桌面页面继续以 Mac 键鼠布局运行；设置、歌曲编辑、桌面歌词已改为自绘内容组件，不再由 debug 的 NSHostingView 面板承载。文件选择、音频输出和窗口仍属于平台适配层。

- 桌面图标改用应用维护的 SVG 路径。桌面歌词使用独立透明 Web 内容窗口，支持字号、锁定、鼠标穿透和窗口位置保存。
- Android 仍在“跨平台界面试用”入口；新增自有缓存统计/清理、后台文件可用性检查、歌手归并、应用内双语/逐字歌词编辑，不再通过该设置页跳到旧原生设置。

### 自有编辑工具继续接入

- 两端共用 LyricsTiming：播放试听、进度拖动、选择行、按当前时间逐行打点、撤销与重选起点。原始行号映射会跳过空行和元数据；重打逐字行时相对平移单词时间。打点先修改草稿，保存沿用各端现有持久化适配器。
- Mac 自有编辑器新增在线封面搜索、下载预览、应用草稿。后台只接受本次搜索生成且绑定歌曲的随机 token，不接受界面指定任意下载 URL；下载校验尺寸后缩至最大 1400 像素。结果数量与错误反馈保留在面板。
- 不支持写标签的 Mac 文件格式仅开放 LRC 歌词编辑，避免展示不能保存的信息/封面操作。Android 原文件标签写入适配仍未实现；不能把应用内歌词覆盖当作原文件标签写入。
- Electron 回归新增打点时间、撤销、封面搜索/预览/应用与脏草稿退出确认。搜索界面使用固定结果验证，真实在线来源的可用性仍受网络与来源服务影响。

## 当前默认接入：自有组件内容界面

此节覆盖上文较早的试用阶段记录。

- Android 启动器、媒体通知定位、扫描通知设置入口统一进入 PortablePlayerActivity + Shared/UI。旧 MainActivity 不再导出，也不再作为通知或设置回退目标；保留源码用于旧版回归参照。
- Mac-debug 主页面、设置、歌曲编辑、桌面歌词、“关于”均由自有 Web 内容组件承载。正式 Mac 产品标识与安装位置继续隔离。
- 两端内容操作按钮统一消费 ActionButton，选择器、复选、数值步进、进度/音量/缩放、滚动条均为应用组件。焦点、Esc/返回、弹窗开关动画和保存/放弃草稿规则共用，触控与键鼠使用各自布局与热区。音乐墙的画布和歌词行保留自身测量尺寸，不套用普通按钮的最小高度。
- Android 歌曲编辑器可实际写入 MP3 ID3v2.3/2.4、FLAC、非分片 M4A 的歌名、歌手、专辑及双语/逐字歌词；旧或特殊 ID3、分片 M4A 及其他格式明确拒绝写入，保留应用内歌词选择。写入需要目录读写授权。
- 文件写入先生成原始备份与候选文件、回读标签，再写入文档并校验 SHA-256。失败尝试恢复原文件，异常中断记录进入设置的恢复备份入口。当前歌曲会暂停文件读取、完成后恢复播放位置和原播放状态。原文件写入后清理相应应用内歌词覆盖；显式应用内编辑优先于内嵌歌词，旧导入回退规则保留。
- 平台适配仍负责音频、文件读写/授权、系统媒体会话、窗口与系统菜单；这些不是应用页面内容组件。Android 在线来源搜索、AI 匹配等功能不因此宣称与 Mac 完全等价。

验证报告：`.build/Shared/Core/full-controls-*`。真实音频覆盖 MP3 v2.3/v2.4、FLAC、M4A 前置/后置 moov，包含中文标签、重复编辑/清空、无关注释保留和解码音频哈希不变；模拟器覆盖默认入口、自有编辑器实际保存、写入中途失败与中断备份恢复。音乐墙/三种样式/主题/滚动返回回归与 Mac 后台测试另行通过。实体手机的材质与 GPU 体验仍需验收。

格式参考：[ID3 结构规范](https://id3.org/id3v2.4.0-structure)、[FLAC 官方格式文档](https://xiph.org/flac/format.html)、[Apple QuickTime 原子结构](https://developer.apple.com/documentation/quicktime-file-format/atoms)。

Mac 音乐墙窄窗口播放按钮修正：主暂停图标使用自有实心双条，图标盒从 18–21px 调整为 24–26px；保留 40–46px 圆形按钮，悬停/按压改为轻量缩放，避免漂移。304px 窗口验证图标居中、实心无描边、播放/暂停切换通过，截图 wall-dock-pause-narrow.png。
播放按钮 SVG 居中补充：清除旧 `.play-main svg` 的 `margin-left:-3px`。此前仅检验 glyph 包装框会漏掉内部图像偏移；回归现同时检验 SVG 视口与实际 path 经屏幕矩阵变换后的中心。
