# 主体页面精细对照

用户本轮参考：`iShot_2026-10-17_14.41.46.mp4`（12 秒）、三张标注截图。设置和编辑器排后，本轮只调整主体页面。

| 差异 | 对照与处理 |
| --- | --- |
| 左上角窗口按钮偏下 | 创建同样 styleMask 的不可见 NSWindow 测量：原生按钮 top=9、left=9、14×14；Electron 从 x=18/y=17 调至 x=9/y=9。系统共享徽标可能遮挡它们，不能据共享徽标位置判断按钮位置。 |
| 封面悬浮后偏离原位置 | 相机平移和悬浮缩放原本施加在同一节点；改成外层定位、内层居中缩放。保持原版 1.025 悬浮、0.96 按下及独立轮廓。 |
| 音乐墙按钮反馈缺失 | 分别复刻 FloatingButtonStyle（1.16、上移 2、按下 0.88）和 ControlStyle（1.2、上移 2、按下 0.86），使用各自 spring 响应和阻尼。 |
| 搜索交互不同 | 从单击展开的独立搜索框改成同一胶囊：悬浮 140ms 后展开 126pt 输入区；移出且搜索为空时收回；点击聚焦；放大镜反馈；全屏退场。 |
| 预览与播放卡片混同 | 预览只显示底部标题、歌手、播放按钮，去掉状态胶囊，使用原版预览渐变。播放卡片保留状态与歌词。 |
| 底部播放器窄窗控件挤压 | 按 MusicWallDockMetrics 连续控制播放按钮 40–46、间距 8–12、内距 12–16；340–440 宽度渐进收起时间和队列。 |
| 播放队列内容不同 | 恢复 300×360 深色队列，标题/首数、歌曲符号、歌手和当前播放项；有界渲染、Esc/点击外部关闭。 |
| 主页面头部错位 | 普通头部与展开头部分别按原版 38pt 与 38+24pt 布局；信息与返回按钮靠右；展开页使用向下箭头。 |
| 歌词页与控件紧贴 | 窄版展开歌词区域与底部控件恢复 12pt 间隔。 |
| 专辑左栏出现多余内层面板 | 取消被浅色主题覆盖的底板；列宽 min(480, 43%)；封面按宽高预算；歌曲信息、收藏、进度、控制和输出按原版排列。 |
| 列表右侧拥挤、列显隐错误 | 复用 MusicListColumns 数学规则，480/660/740/820 断点；分别锚定标题、歌手、专辑、时长、收藏/编辑；单独保留滚动条区域。 |
| 图标/悬浮细节 | 应用图标提示改为原版 SF symbol、仅悬浮出现；收藏使用 heart/heart.fill；头部浅底细边、收藏按钮缩放、滑杆悬浮/拖动缩放。 |
| Logo 外侧异常底板 | 清除按钮默认内边距、底色和矩形 box-shadow；悬浮阴影改为图片 alpha 轮廓的 drop-shadow，保留旋转、缩放和切换提示。 |
| 覆盖侧栏点击行为 | 音乐墙窄窗覆盖侧栏时显示 18% 黑色遮罩，点击外部收回，避免直接触发后方卡片。 |
| 音乐墙展开后丢失拖动位置 | 保存展开前相机位置及卡片实例，收回到原位置；展开期间切歌时，按恢复后的侧栏宽度居中新卡片。 |
| 展开/收回时按钮和边框提前出现 | 600ms 过渡门控；收回完成后显示外围控件，过渡期间隐藏最终选择描边；中途切样式或导航清理展开状态。 |
| 卡片变形时封面被拉伸 | 封面独立反向抵消 FLIP 非等比缩放，按图片真实比例覆盖中间帧；文字仍随原卡片过渡，滚动相机继续使用合成变换。 |
| 分类页缺少内容和紧凑状态 | 补回工具栏、分类数量、专辑歌手名、无封面占位；按原版 136pt 最小卡宽/16pt 间距排列，单列转为 54pt 封面的小卡片。 |
| 分类页动画与返回入口 | 列数改变按原版 .28/.92 弹簧移动卡片；详情返回放入工具栏，保留网格和滚动位置；列表与播放器之间恢复 12pt 留白。 |
| 滚动条常驻及操作细节 | 主体列表/分类/歌词滚动条滚动时显示，停止 1.4s 后隐藏；工具栏悬浮恢复绿色、缩小图标；输出设备弹层支持外部点击及 Esc 关闭。 |
| 窄窗与播放区细节 | 保存尺寸允许 304–719pt 窗口恢复；纵向展开页的宽行控件高度为 120pt；封面提示使用上下箭头，音乐墙收藏实心态和 00:00 时间格式补齐。 |
| 卡片按钮挡住墙面滚动 | 不再统一忽略 button/input 上的 wheel；卡片歌词、播放、切歌、收藏、模式、展开、进度条均把滚动交给墙面，并 preventDefault 避免滑杆误改时间。浮动工具弹层保留自身行为。 |
| 聚焦卡片大小固定 | 复用原版聚焦偏好 min(520, max(320, (height - 150) × 0.85))，聚焦变化时更新，窗口调整时按剩余宽高约束。 |

## 验证边界

编译、几何回归和实际界面操作分开记录。不得以构建成功替代悬浮状态、视觉材质或屏幕帧率验收。Chromium 的背景模糊并非 macOS 26 原生 Liquid Glass 的同一渲染实现，材质仍需单独比较。

本轮已在运行包检查音乐库头部/滚动留白、宽版专辑页顶部按钮/封面/左栏底板、音乐墙搜索展开和移出收回、应用图标悬浮退出，以及 1040 首队列弹层（只挂载视口附近项目）。窗口切换和边缘拖动验证遇到工具超时，窄窗真实 UI 仍待完成。15 项桌面测试通过，含新增底部胶囊连续布局与 280–1600pt 表格列不重叠检查。全应用 1:1 验收尚未完成。

后续补齐后的运行包通过 18 项桌面测试及深度签名校验。实际界面再次检查音乐墙展开/收回、外围控件隐藏/恢复、专辑工具栏与数量/歌手名、进入详情并返回、分类页底部 12pt 间隔、光盘占位图；已观察到分类网格三列与两列布局。对单列紧凑布局和动画中间帧比例有几何测试，不能将其记为对应尺寸的真实屏幕验收。极窄窗口、所有悬浮中间态、原生材质和字体基线仍未完成逐像素验收；设置/编辑页按用户要求后排。

卡片滚动穿透修复已重新构建运行包并通过签名校验，相关几何/动画回归通过。原生界面工具在定位/截图/滚动验证中多次 30s 超时并重置，期间用户也切换页面和播放歌曲，未取得稳定的同一控件滚动前后对照；此项仍需实际手势验收，未标记为 UI 实测通过。
