# 主窗口 1:1 还原差异清单（2026-10-18）

此清单对照仓库 SwiftUI 原版与当前 Electron 实现。代码、构建、自动化测试通过不等于逐帧视觉一致；本轮 Mac 锁屏，新增修复尚未完成实机截图验收。不能认定已完全 1:1。

## 本轮已改，待实机验收

- 窄窗口侧栏覆盖时，遮罩覆盖顶部区域，补回上方缺失的暗底色。
- 多选工具栏允许按钮换行，避免最窄窗口横向裁切；加入歌单菜单限制在容器宽度内。
- 简易、音乐库和音乐墙的最近播放入口均隐藏重新扫描、排序；音乐墙仍保留缩放设置。
- 静态页面文字与图片禁止选择和拖拽；可编辑输入框、文本域与 contenteditable 保留文本选择。
- 音乐墙设置弹层按视口、底部按钮和顶部安全距离限制高度，内部滚动，关闭标题保持可见。

## 确认仍有实现差异

| 优先级 | 项目 | 证据与差异 | 后续验收 |
| --- | --- | --- | --- |
| P1 | 侧栏覆盖的纵深动画 | `MacOS/Sources/MiniVoice/ContentView.swift` 的原版工作区还会按覆盖深度缩小至 97.5%，向下偏移至 8pt；当前补回遮罩，未完整复制这组变换 | 简易、音乐库各取并排、半覆盖、最窄终态和过渡录像 |
| P1 | 液态玻璃 | 原版系统材质与当前 CSS / SVG 自绘玻璃的折射、边缘高光和取色机制不同 | 同封面、同窗口尺寸、同悬浮状态逐项对照，不能以“有模糊”代替一致 |
| P1 | 歌词字体与动效 | 当前 DOM / canvas 与 SwiftUI TextRenderer 的排版、渐隐和逐字渲染路径不同；普通歌词空句为音符，原生 LyricsTiming 使用三个圆点 | 当前行、上下文、空句、译文、长句换行及暂停状态分别检查 |
| P1 | 拉伸与展开过渡 | 当前 CSS / WAAPI 近似原生弹簧，尚无同尺寸连续拉伸逐帧对照与卡顿测量 | 重点检查播放条位移、右侧白边、搜索展开 / 收起和侧栏开关完整动画 |
| P2 | 右键与设备菜单 | 主窗口 HTML 菜单与原生 contextMenu / popover 不同；部分操作仍用字符图标 | 核对字重、图标线宽、行高、背景和定位 |
| P2 | 播放滑块 | HTML range 自绘与原生玻璃滑块的滑块高光、轨道和按压反馈不同 | 墙内、底部、简易播放器及音量条分别对照 |

## 尚需系统验收，不能宣称已恢复

- 播放卡片青绿色描边、外发光、白色悬浮描边在不同缩放下的厚度与裁切。
- 顶部侧栏 / 搜索和右下角设置按钮的图标居中、悬浮高光与取色。
- 60% / 100% / 120% 缩放、最小窗口、多选换行后的内容可见性。
- 歌手 / 专辑一级页与歌曲详情切换，播放卡片不混入分组卡片。
- 设置与歌曲编辑仍为原生窗口，但从新主窗口打开后的窗口大小、层级和外观仍需与原版对照。

## 用户指定行为优先

最近播放去掉扫描 / 排序、仅输入框参与 Tab、静态文字不可选择、缩放 60%–120%、搜索按钮先整体放大再展开，均按最新要求执行，不以旧版不同作为回退理由。
