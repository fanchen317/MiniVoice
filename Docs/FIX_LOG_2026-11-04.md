# 2026-11-04 播放界面修复日志

范围：用户本次 Mac 体验版、Android 体验版与 iOS 清单。按用户要求，不执行此前灰屏排查任务。以下“已修改”指代码已落地；流畅度不以编译或模拟事件冒充真机验收。

## Mac 体验版

- 封面边缘白线：移除悬停白色轮廓与旧海报边框，保留当前播放强调；移动端按压也移除同类白轮廓。
- 独立设置/编辑窗口：移除内容标题的第二处拖窗区域，由系统标题栏承担拖动；独立窗口不再使用内容面板阴影、模糊和入场 CSS 动画。歌曲编辑的播放时钟订阅下沉至歌词打点组件，播放进度不再让整个编辑页面重绘。实际拖窗帧耗时仍待实体 Mac 验收。
- 编辑页面：保留歌曲信息、歌词与翻译、插图三个分类；增加对应图标，重排名称/专辑、歌手输入和移除操作；歌词原文与翻译在宽窗口并排，窄窗口顺排；插图保持完整预览。移除截图标出的两段说明。
- 文件名识别无法提取时给出明确错误，避免点击后无反馈。原有保存、歌词保存位置、导入、搜索、时间轴、封面、Finder 操作仍走既有服务。新增测试覆盖歌手草稿、三分类、识别失败与保存命令；真实音频标签保存回读本轮未重新验收，不能称全部按钮已做文件级验证。

## iOS 音乐墙

- 卡片点击回流：内容使用最终布局后随外框变换，减少变形中按钮、歌词每帧重排；保留同一真实内容节点和完整遮罩。
- 高清封面解码交接延后至聚焦/全屏过渡稳定，避免图片升级与几何动画竞争。
- 双指缩放：启用已采集的封面/内容布局快照，手势期间仅变换；普通滑动的绘制捷径在双指期间禁用，松手提交真实尺寸。保持系统原生滚动方案。
- 正方形、全屏展开/收起、反向打断、相机保持与 pinch 遮罩同步进入回归。模拟器不证明手机发热或帧率已达标。

## 移动端共用

- 小卡片歌词：消除高度 60px 前后的字号突变；除极小视口外保留相邻歌词，避免最小缩放突然只剩一行。
- 普通歌词：字号由可用宽度决定，展开增加可见区域，不再因为“展开模式”切到另一套更小字号。
- 歌词居中：手动滚动结束后约 2 秒恢复居中，长时间停留同一句也可恢复；旧逐字高亮离开后清理，回到同一行重新建立绘制缓存。
- 音乐库：移除排序右侧的“正在播放”展开按钮。播放条只允许点击插图按钮展开，标题区域不再触发展开；增加播放器出现的位移/淡入，遵循减弱动态效果。
- 搜索：保留持续容器开合；输入聚焦延后到开启动画后，避免键盘与初始布局同时变化；遮挡测量先读后写，仅提交发生变化的状态。尚无手机帧耗时对比证据。
- 设置：去除“启用扫描通知”“返回播放器”。打开音乐库维护时启动真实可用性检查并轮询结果，显示 checked/total 与不可用明细；日常增量扫描和显式文件完整性检查属于不同操作，不把未检查误显示成零故障。
- 首次引导：通知请求之后进入音乐文件夹授权；拒绝/取消不反复强制弹窗，后续可从设置添加文件夹。自动测试夹具跳过首次引导。
- 简易：补充侧栏多选、已选数量及批量操作。简易/音乐库的歌曲长按菜单增加多选入口；菜单层级高于侧栏。
- 侧栏：保持同一开合动画与可打断行为；缩放绘制和搜索测量的重复工作已减少。实体手机掉帧、偶发按钮失效仍需触控回归。

## 全平台共用

- 歌词时钟：普通宿主采样抖动不再让预测进度回退；渐进校准，明显跳变立即按 seek 处理；滚动歌词用插值进度切行，移动普通歌词不再经宿主异步往返决定当前行。
- 逐字绘制：清除旧行高亮时同时失效缓存，修复回到旧行后只保留旧尺寸/高亮状态。只有逐行时间戳的 LRC 仍为估算逐字时间，不等同真实逐字标注。
- 音乐墙全屏：歌词样式按钮旁增加水滴图标，切换清晰封面/高斯模糊；使用预览图静态模糊加透明度过渡，避免逐帧改变大图模糊半径。偏好为当前展开会话局部状态，不写入歌曲或播放数据。
- 全屏裁切：32×32 缩略图对比度分析加中央权重估计视觉重点，限制偏移范围；继续以 cover 铺满屏幕，按焦点选择保留区域。最多缓存 128 个焦点结果；不可读取像素时居中回退。它不是人脸识别，也不保证每张图的所有人物/文字都能保全。

## 权限核实

Android 清单包含通知、前台播放/扫描服务、唤醒和音频设置；需要用户运行时确认的是通知与文件夹授权，未增加定位、麦克风、相机或全盘文件权限。iOS 使用通知请求与 security-scoped 文件夹选择器。文件授权由用户选择具体目录，不能用一个通用“允许访问全部文件”弹窗替代。

依据：[Android 文件夹授权](https://developer.android.com/training/data-storage/shared/documents-files)、[Apple 目录授权](https://developer.apple.com/documentation/uikit/providing-access-to-directories)。通知由各宿主已有系统 API 请求。

## 补充：移动端长时间打开后的超时提示与收藏轮廓

- 排查到共享宿主通信使用固定墙钟 10 秒超时，自动 snapshot 每 450ms 持续轮询，未明确处理页面隐藏/恢复。截图能确认提示来自该超时路径，但未在用户手机复现长期前台运行的全部诱因，不把后台挂起认定为唯一根因。
- iOS/Android 共用桥改为单个计时心跳，仅累计可响应的前台运行时间。隐藏时与长时间事件循环挂起不消费请求预算，唤醒时允许已排队的宿主回复到达；前台宿主持续无响应仍超时，不隐藏真实错误。
- 自动 snapshot 只允许一个在途请求，隐藏后停止轮询，恢复后立即读取；失败退避 1/2/4/8 秒，不补发后台积压。连续三次失败才提示，同一失败过程仅提示一次，恢复后仅清除对应连接提示；用户主动播放/收藏/写状态命令不自动重放。
- 收藏爱心：三种移动样式、列表与卡片统一去掉常驻背景、描边、阴影和采样。已收藏保留爱心实心/强调色；按住有圆形背景反馈，释放消失。键盘操作仍保留 focus-visible 可访问焦点。
- 新增确定性生命周期回归：隐藏一分钟、事件循环挂起两分钟、恢复、真实前台超时、单请求轮询、失败退避、只提示一次及恢复。共享单测共 61 项通过；iOS Debug 模拟器构建与实际 WK 墙矩阵通过，结果 `20261104T075331Z-27408`。长期真机前台运行与 Android 原生宿主提示仍待持续使用验收。
