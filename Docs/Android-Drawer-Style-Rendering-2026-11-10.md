# Android 侧栏、样式切换与短暂黑卡片（2026-11-10）

## 用户范围

修复打开侧边栏偶发闪屏、样式切换卡顿，以及滑动/缩放后新卡片短暂成片黑色。保持现有动画样式、碎片计划、轨迹、关键帧、时长、玻璃材质与Android布局。未新增平台或原生内容面板。

## 可复现原因和处理

- 黑卡片：快速移动到新海报、阻塞图片响应时，新img尚无像素，原`.mv-wall-press-surface`直接露出纯黑底。合成测试修复前采样RGB=0/0/0。Android海报底层现复用应用已有占位渐变；有效封面覆盖后与原遮罩相同，白图采样仍168/168/168，等待时为41/49/57。上述数值仅属于这个用例，不是FPS或对比度验收。它处理确定的冷图等待露黑；设备GPU纹理丢失等其他黑屏原因不能据此一概关闭。
- 侧栏采样：旧实现换style/相机时立即替换图片，新的图像未decode就参与材质，短暂露出纯tint；viewport扩展采样也会在未就绪时替换。现在隐藏候选层加载/解码，提交复用同一已解码DOM，旧层立即隐藏避免两份opacity叠亮，保留引用两帧后释放；候选代次防止迟到覆盖。每实例最多候选/当前/退休三层，关闭保留一份有界last window，下次打开复用；稳定采样按字段比较，避免每帧序列化大data URL。
- 侧栏运动：首次closed不启动看不见的320ms动画，快速反向从当前矩阵接续；运行时开启减弱动态取消旧运动并使用真实终点。原320ms曲线、深度变换和blur24采样不变。
- 样式切换：原JPEG已在后台编码，但整张图会通过Base64/JSON/evaluateJavascript大字符串跨桥。现在只发布单份、受限same-origin本地资源，桥传src/token；裁片完成即释放，超时/取消的迟到结果也释放。原1.2MP/1600与JPEG85预算不变，取消/新代次不能发布旧图，资源五秒TTL只按匹配token回收；只允许GET数字token，no-store，不提供任意文件读取。
- 动画准备：首批8片不再额外等待一帧；每片只裁一次。原移动上限24片、实际plan、17个关键帧、480ms加各自delay、690ms窗口以及180ms捕获预算保持。Mac/dataURL与iOS host-fragments继续兼容。

## 验证

- `test-wall-pending-artwork.sh`：真正新挂载海报+阻塞协议响应，验证等待不露纯黑、释放后解码并恢复原遮罩。
- `test-drawer-sampling.sh`：延迟加载时旧玻璃和边缘仍可见，提交复用pending已解码图，退休释放，过期C不能盖D，重开/切style不清空采样，材质和运行时减弱动态保留。
- `test-style-snapshot-motion.sh`：原plan和所有关键帧/矩阵/opacity/延迟/时长等价，每片一次drawImage，正常/迟到release、预算和减弱动态清理。CSSOM矩阵序列化比较容差.001 CSS px，远小于一物理像素，未改变产品参数。
- 共享、桌面、组件和完整页面，以及最终Android APK/portable的实际结果见`ACCEPTANCE_STATUS.md`。首次原生采样不足等失败保留；不通过降低中间帧要求宣称流畅。实体设备的偶发WebView合成闪烁和热状态仍需原设备验证，没有声称实测FPS。
