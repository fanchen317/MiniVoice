# MiniVoice 自有组件契约 v1

本文件约束新建和修改的组件，与产品标准共同执行。只实施 Android 与 Mac 体验版；标准建立不代表存量组件已全部验收。`Shared/UI/COMPONENTS.md` 记录具体实现，本文件规定必须遵守的规则。

## 1. 分层与依赖

依赖方向为：页面 → 组合组件 → 基础组件/纯行为模型；主题、图标、输入策略为组件提供配置。平台能力经页面/业务适配层注入，不能倒流进入通用组件。

- `Shared/UI/src/components/` 不导入平台目录、宿主桥、页面或状态存储，不直接发网络请求、读写持久化、发播放/文件命令。允许标准 DOM、React、共享纯模型与组件内局部状态。
- 组件发语义事件，由页面决定调用哪个业务服务。播放按钮请求播放，不能自行找到 Android 服务或 Mac 后台。
- `presentation` 决定触控/键鼠家族，视口决定家族内部布局；基础组件不判断操作系统字符串。平台能力按可用能力处理，未支持要明确反馈。
- 宿主负责音频、文件、授权、通知、窗口与系统菜单。换宿主仍需适配这些服务，不能把共享 UI 说成无需移植即可运行。

## 2. 每个组件的必备说明

新增或修改组件时，在实现说明中写清以下内容；不适用项写明不适用，不为凑统一接口加入无意义参数。

| 项目 | 必须确定的内容 |
| --- | --- |
| 身份与职责 | 名称、稳定的 `data-mv-component` 标记、解决的问题及边界 |
| 状态所有者 | 哪些状态受控、哪些仅局部；默认值、重置条件、卸载清理 |
| 输入与事件 | 参数、语义事件、提交/取消时机；是否异步；错误交给谁显示 |
| 交互 | 触控、鼠标、键盘、焦点、禁用、忙碌、取消、连续触发 |
| 外观 | mobile/desktop、library/simple/wall、深浅主题；尺寸、图标、材质与命中区 |
| 动画 | 起止状态、打断规则、减弱动态效果、最终真实布局 |
| 验证 | 行为用例、渲染用例、平台接入证据、已知限制 |

## 3. 状态与事件规则

- 受控值以调用方为唯一事实来源。组件只保留手势预览、焦点和过渡等临时状态，不复制音乐库或播放器状态。稳定对象身份用于重置，不能依赖数组序号。
- 新值控件沿用 `value`、`onValueChange`；区分预览与持久提交时使用 `onCommit`、`onCancel`。开合使用 `open`、`onOpenChange`。存量不同命名迁移时保留兼容，不悄悄改变回调含义。
- 一次手势只提交一次；取消不得提交。拖动期间外部轮询不能覆盖预览；换对象、禁用、失去捕获、卸载必须结束旧手势。异步结果不得覆盖后来的操作。
- `disabled` 不触发业务事件；`busy` 防止重复提交并保留可读状态。业务失败不能假装成功，草稿保留由页面负责。纯组件不弹系统提示。
- 普通按钮默认 `type="button"`，都经 ActionButton；选中与按下分开，开合使用 `aria-expanded`，忙碌使用 `aria-busy`。禁止只换颜色而没有语义状态。
- 文本输入保留 IME 合成，不在合成期间触发提交/全局快捷键。事件冒泡、返回与 Esc 的消费边界要明确，最上层只消费一次。

## 4. 外观和输入策略

- 行为共用，皮肤分样式，布局分设备家族。一个组件不复制成三个相互偏离的业务实现；确实不同的组合结构允许分开，但复用基础行为。
- 新组件的颜色、描边、材质、圆角、命中区、动画参数使用组件变量或现有主题变量；禁止跨组件 SVG 负偏移和依靠样式加载顺序修正几何。存量硬编码逐项迁移，不声称已统一所有 token。
- 样式通过明确的组件根和样式状态作用域生效。背景层与内容层分离，模糊不能模糊正文；开合、重开、换样式都要验证采样源与裁切。
- 触控目标至少 44 CSS px，桌面至少 28 CSS px；图标大小与命中区分开。缩放画布例外按产品标准显式记录。图标来自自有 SVG 库，检查实际路径居中。
- 手机保留触控反馈，电脑提供 hover、焦点环和键盘导航；不能靠宽度切换产品家族。语义 DOM 和标准输入可用，但不直接采用系统内容控件外观。
- 动画不能决定业务是否成功；重入以最新意图为准，停止旧定时器/监听器/捕获。变形保留同一根容器，结束尺寸与实际布局一致。

## 5. 首批契约与验收重点

| 组件 | 行为契约 | 必测边界 |
| --- | --- | --- |
| ActionButton / Icon | 名称、禁用、忙碌、选中；自有路径 | 重复触发、键盘、实际绘制中心 |
| Slider / NumberField | 规范化值；预览/提交区分 | 端点、取消、外部更新、换对象 |
| CheckControl / Choice | 受控选择、禁用项不触发 | Space/Enter、菜单关闭、焦点恢复 |
| Menu / DialogBoundary | 顶层事件与焦点归属 | 嵌套、Esc/返回、边缘避让、卸载 |
| ScrollRail | 空闲隐藏、活动显示、可拖动 | 无溢出、取消、内容变化、顶部按钮避让 |
| SearchControl | 受控开合和查询；持续容器变形 | 快速开合、IME、返回、焦点、安全区 |
| SurfaceMotion | 只管理过渡，不持有业务状态 | 打断、退出幽灵不可交互、减弱动态 |
| LyricsTiming | 编辑草稿，显式保存 | 撤销不覆盖后续草稿、时间校验 |

新组件先复用上述契约；需要新增类别时补说明和失败用例，再接页面。公开参数/事件破坏性变更须同步所有调用方与测试，记录迁移，不留下两套默认行为。

## 6. 执行与真实进度

构建门禁检查组件直接依赖和禁用 API，并用反例测试验证检查器。静态规则只覆盖可识别的直接引用，不等于完整依赖图、安全审计或运行验收；评审仍需检查间接依赖。

共享模型用单元测试；真实 DOM 验证键盘/触控/焦点/打断；两端集成验证平台事件。每项分别记录证据，不用组件数量或完成百分比代替验收。受影响的样式、主题和输入家族必须覆盖，实体设备材质/流畅度仍单独验收。

当前缺口：存量 CSS token 与样式作用域尚未全量收敛，部分 disclosure/details 仍需统一，所有组件的契约用例尚未完整登记。按本标准逐项整改，不将这些缺口视为允许新增同类实现的例外。

## 7. 已接入的按钮反馈接口

ActionButton 的 `feedback` 默认为 `standard`：按下缩至 .98，支持精确指针悬浮时放大至 1.015，键盘操作显示焦点轮廓；禁用/忙碌不激活。`feedback="none"` 用于已有专用变形的组件，避免重复运动。比例与 140ms 时长由 `--mv-feedback-press`、`--mv-feedback-hover`、`--mv-motion-feedback` 控制，皮肤可显式覆盖。独立 scale 不改写用于定位的 transform；组件已有 transition 优先，禁止为通用反馈覆盖原有变形过渡。系统减弱动态效果和应用 reduce-motion 均取消缩放。

页面切换/弹窗继续复用 SurfaceMotion，搜索保留持续容器变形。此处不是全页面动画已完成的声明；大画布聚焦与返回仍按各自实际页面验收。

## 8. 材质与滑块内部作用域

基础材质参数由 `Shared/UI/src/components/materials.css` 提供，移动端及 Mac 简易/音乐库复用基础皮肤；按用户要求，Mac 音乐墙按钮与播放栏使用正式 Mac 页面参考的独立薄玻璃皮肤，采样层由 surfaceRefinement.css 管理，播放栏几何与转换由 wallDock.css 管理。触控/键鼠尺寸和布局分别适配。修改共享文件时同时验收两端实际材质，不再要求不同命名皮肤的计算样式完全一致；不能用无背景采样的纯色层代替玻璃。

时间标签使用 `.seek > span`，不得以 `.seek span` 等后代规则污染 Slider 内部轨道和滑块。轨道与滑块只能由组件自身样式/变量控制，桌面进度滑块与移动端同为圆形，拖动放大保持等宽等高。音乐墙播放卡片的专辑图必须是显式图片层，当前播放/暂停/预览均验证加载成功，不以模糊颜色或底层偶然透出代替。

## 9. 空闲收起与图片交接

播放条共用 useIdleCollapse：空闲 3 秒收起；按住、鼠标悬浮、键盘焦点和阻塞面板期间不收起，卸载清理计时器。Mac 悬浮展开、触控点击展开；收起不改变播放状态。根材质容器持续存在，Mac 配置按钮按实际播放栏碰撞决定是否上移，不因展开状态无条件上移；收起时回到右下。必须用中间帧验证宽度和位置，不能只检查最终圆形。禁用动态效果时直接到最终状态。

图片升级/切换时保留已加载底层，新图解码完成才接管；异步旧结果不得覆盖新歌曲。保留封面节点与几何连续性、图片解码就绪是独立检查，不能只凭 img 元素存在断言没有闪屏。实体 GPU 的合成闪烁仍需真机录屏验收。
