# Electron 主窗口迁移

用户选择 Electron + React，以验证与 Folia 相同的窗口/浏览器渲染路线。实现和构建说明见 `Desktop/README.md`。

原生入口新增 `--desktop-engine` 模式；无此参数时仍启动既有 SwiftUI 版本，以便对比和回退。Electron 主窗口的三种样式、设置和编辑器均由 React 构建，原生后台不承载主界面。

已修复打包后 `UserDefaults(suiteName:)` 与应用自身 bundle ID 相同时返回 nil 的启动问题；此时改用 `.standard`。打包应用的通信、音频播放/暂停/seek/歌词读取已通过独立静音音频测试。

真实曲库初验时发现 macOS 文件访问在 `open/getxattr` 等待，正值屏幕再次锁定，尚需解锁后确认曲库访问及实际播放。静音测试音频位于临时目录，不受原曲库位置的访问权限影响。该现象不应通过伪造播放状态或隐藏错误处理。

## 原版外观还原（用户新增约束）

迁移以原 MiniVoice 为视觉基准，不采用 Folia 的产品外观；Folia 仅作为滑动体验参考。

- 去掉 Chromium Edition / Electron · React 标识和额外的宣传式标题。
- 音乐墙恢复全窗口拼贴、左右上角浮动侧栏/搜索按钮、右下设置入口；底部恢复 64pt 胶囊（左侧白色播放、中央标题/前后曲/进度、右侧模式/队列）。海报字号按自身宽度计算，采用原版数值和 5pt 间距。
- 简易样式恢复左侧歌曲列表、右侧横排封面信息和独立歌词卡片；音乐库恢复歌曲列表主体，不再常驻右侧歌词面板。
- 面板采用原版 12pt 外边距、34pt 顶部起点、250–288pt 侧栏、16pt 圆角及封面色调背景。模糊仅用于固定背景和浮层，不进入音乐墙滚动平面。
- 样式入口回归侧栏品牌图标循环切换；菜单亦可直接切换三种样式。

第一轮已实测全窗口音乐墙和简易样式显示。仍为近似还原：Chromium 与原生材质、字体度量存在差异，尚不能声称逐像素一致。高级功能迁移缺口仍以本文和 Desktop/README.md 为准。

最终包已重新构建、签名验证通过；6 项桌面集成测试通过。三种样式均已在运行窗口查看，品牌图标循环入口经实际点击验证（简易 → 音乐库）。移除了音乐库中已隐藏的旧歌词详情组件，避免隐藏视图继续订阅播放时钟。播放队列使用虚拟列表。

原曲库文件读取问题仍未验收：解锁后已通过文件夹选择器重新选择原音乐目录；歌词最终能够载入，但播放曾持续处于准备状态。进程采样显示文件 `open` / `getxattr` 等待，独立 Python 对同目录真实 FLAC 的 4 字节读取也在 5 秒内未完成。因此当前证据不足以归因于窗口框架或确认音频播放正常；临时 WAV 的实际解码和进度测试通过。
