Windows 安装位置：默认当前用户 LocalAppData/Programs/MiniVoice，安装向导提供目录选择；重装优先读取上次 InstallLocation。所选位置必须可写，当前包不申请管理员权限。禁止直接选磁盘根目录和系统/Program Files 根目录；用户可选其他专用应用目录。卸载仍按打包文件清单删除，不递归清空用户目录，音乐和偏好不在安装目录内。

用户要求是完整对齐，上表是尚未关闭的工作项，不是被允许省略的范围。自动化/本机类型检查无法替代 Windows 实机证据。
