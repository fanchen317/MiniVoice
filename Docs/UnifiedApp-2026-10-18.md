# MiniVoice 单一应用与还原实施记录

## 正式入口

- 构建：`Scripts/build/build-app.sh [debug|release]`。
- 唯一正式应用：`.build/dist/MiniVoice.app`。
- 安装：`Scripts/deploy.sh`；安装镜像：`Scripts/build/build-dmg.sh`。
- `build-electron-app.sh` 仅调用同一构建，不再产出另一种应用版本。
- Swift 可执行文件仅在 `--desktop-engine` 下运行音频、曲库与原生辅助窗口；普通运行只提示统一应用入口。原 SwiftUI 主窗口不再是可启动的发行路径。
- 主应用与内置服务保留已有标识、签名和偏好域，避免因为统一名称而更换用户身份；前端样式、曲库、收藏、歌单和原生设置继续沿用。
- 新主应用使用单实例锁，重复启动会显示已有窗口。

## 已实施的还原

对应 `InterfaceParityReaudit-2026-10-18.md` 中的 A01–A19：

- 定位目标与选中项解耦，等待列表到达后处理一次定位请求；初始与导航定位恢复。
- 统一歌手/专辑名称的 trim 与未知名称，分组和详情使用相同规则。
- 空状态限制在列表内容区，不覆盖返回和工具栏。
- 歌曲、歌手、专辑各自保存排序字段和方向，沿用原生偏好，并迁移旧排序键。
- 切换样式清理搜索、分类、多选与展开状态。
- 歌单重命名、删除、创建后导航；共享加入歌单选择器，支持新建并加入、已加入标记、批量加入与批量移除。
- 单首/多首删除确认及移至废纸篓选项；取消不写入。
- 最近播放清空菜单；扫描、AI 匹配、模型下载的后台任务面板及重试/清理。
- 曲库增减后保留墙面位置；展开中移除聚焦歌曲时恢复外围控件。
- 侧栏遮罩、共同缩放支点、下沉、窄窗导航收回及 Esc 顺序。
- 列表封面飞入播放器动画；播放器完整显示非方形封面，模糊背景补边；列表与墙面使用各自的图片适配。
- 普通播放器 28×18pt 进度滑块、范围 1% 的键盘步长、换曲清理拖动状态；音乐墙保留独立的 8pt 滑块。
- 普通歌词空句、长句缩字、系统减少动态效果；逐字高亮按浏览器实际换行片段累计宽度绘制，保留文本排版与字距。
- 输出设备图标、勾选、空状态、错误提示、滚动高度，选择失败时不关闭面板。
- 信息、静音、桌面歌词和多选状态图标；原版播放模式图标、菜单次序及循环次序。
- 空页面、无曲目控件状态；音乐墙预览与当前播放分别处理。
- 共享模态边界、输入框 Tab、Esc 取消、焦点恢复，错误保留至关闭。

## 歌词视觉优化

按用户新截图反馈调整音乐墙滚动歌词：移除背景裁切文字及逐字 span 的重复阴影，改为在文字合成后施加一次轻阴影，修正当前句出现浮雕与压黑的问题；字重使用 600，未唱部分透明度约 44%，前后句按距离使用 50% / 32% / 20% 的层级，取消非当前句模糊。保留原版字号、行距、居中位置及滚动时序。

已用同一句逐字歌词复现修改前后的差异，并检查浅色背景、跳转歌词、304×600 窄窗；4 项歌词时序与扫色测试通过。截图和日志位于 `.build/lyrics-style-qa/`。这部分是依照用户反馈的视觉优化。

## 玻璃、圆角与浮层动效优化

本轮保留当前按钮和紧凑面板尺寸，按用户要求调整材质、文字和动画：

- 玻璃背景、滤镜与外阴影分层，背景沿圆角单独裁切；折射图使用控件实际圆角，取消按大小推测圆角。大侧栏增加柔和模糊，文字与图标保持在滤镜之外。
- 简洁页与普通音乐库的布局容器保留阴影显示空间，取消矩形裁切；封面沿父级圆角裁切，分类详情避免重复铺两层背景。
- 设备、排序与墙面设置使用 body 浮层和实测尺寸定位。浮层随窗口缩放与侧栏动画更新位置，打开动画的支点和方向来自按钮实际位置。
- 对话框与浮层采用 260ms 轻缩放进入、140ms 淡出，退出残影不可点击、不可聚焦并自动清理；保留模态边界与焦点恢复，减少动态效果时即时开关。
- 简洁页长标题在原字号 85%–100% 内适配两行；窗口唤回统一恢复最小化状态并聚焦。

验证：51 项前端/后台测试、17 条交互回归、48 组主题/窗口尺寸检查通过；新增 8 条实际界面检查覆盖圆角裁切、面板尺寸、快速开关、连续缩放、独立浮层、减少动态效果和焦点恢复。截图和日志位于 `.build/surface-qa/`。窗口唤回修改完成语法检查，未对用户正在运行的实例执行最小化/唤回操作。统一应用及 2.7.0 镜像已构建，前端资源与主进程哈希核对一致，镜像只读挂载后的前端/原生服务哈希与深度签名校验通过。打包脚本同时修正临时目录路径规范化，避免 /var 与 /private/var 差异妨碍失败后的卸载清理。

## 验收边界

功能修复、主窗口几何对照和打包成功，不等同于整套应用逐像素 1:1。

CSS / SVG 玻璃仍与系统 NSVisualEffectView / Liquid Glass 的实时取色、折射路径不同；字体栅格化、所有主题及尺寸下的动效中间帧、连续拉伸与 120Hz 帧时间仍没有完整双端验收。不能将这些项目标记为已达到完全相同。

60%–120% 缩放、最近播放隐藏扫描/排序、静态文字不可选择、仅文本输入参与 Tab、搜索先整体放大再展开，继续遵循用户要求，不以旧版不同而回退。
