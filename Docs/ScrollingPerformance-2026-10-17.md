# 滚动与音乐墙动效

本次以用户提供的 MiniVoice / Folia 对比视频和本地 Folia 运动参数为参照。未把录屏中的帧率当作应用真实帧率；录屏本身为 30fps。

## 渲染路径

- 音乐墙海报放入带 384pt 预留边缘的 `NSHostingView`，由 `NSClipView` 平移。相机的每帧更新直接调整原生裁剪层，不通过海报的 SwiftUI `body`。每跨过 192 × scale 的空间分桶才重新查询、挂载可见海报。
- 每次更新可见内容时，同时重置文档坐标原点和裁剪原点，保持画面位置。原生视图坐标也用于菜单及辅助功能命中。
- 聚焦播放器保持独立，继续使用视口坐标投影，保证歌词、按钮和输入排除区域一致。让位时的尺寸变化仍由 SwiftUI 布局处理。
- 相机惯性、滚轮、定位、缩放和让位共用一个 `CADisplayLink`，通过承载视图跟随所在显示器，在 `.common` 模式运行。没有运动时停止时钟。macOS 13 使用按刷新率设置的兼容计时器。
- 动画使用单调时间；触控板原生惯性只合并到下一显示帧，不附加一条惯性曲线。

## 手感参数

- 拖拽松手：速度阈值 40pt/s，向量速度上限 4000pt/s，目标距离为速度 × 0.3，衰减时间常数 280ms；剩余距离小于 0.5pt 后精确收尾。最后一次移动超过 80ms 时不启动惯性。
- 离散滚轮：80ms 指数平滑，单帧时间上限 50ms，剩余距离小于 0.5pt 后精确收尾。
- 定位：420ms，三次贝塞尔曲线 `(0.22, 1, 0.36, 1)`。
- 海报让位：单位质量、刚度 300、阻尼 34 的解析弹簧；520ms 后收尾。
- 减弱动态效果时，滚轮直接位移，拖拽不滑行，定位与让位立即完成。

## 其他样式

- 艺术家/专辑卡片的实时坐标保存在不发布视图更新的存储中，打开/返回卡片时读取，避免滚动偏移触发整个工作区刷新。
- 列表及歌词渐隐遮罩只订阅顶部/底部阈值变化；像素级位置只更新滚动条。
- 小封面优先使用列表缩略图，较大卡片使用浏览封面。浏览封面准备阶段在后台解码，使用有容量限制的内存缓存，降低首次绘制时的解码开销；缓存未命中仍保留立即显示压缩封面的兼容路径。

## 验证

```sh
swift test --disable-sandbox --filter 'MusicWall|DisplaySynchronizedMotionTests|PreparedBrowseArtworkTests'
swift test --disable-sandbox
Scripts/build-app.sh release
```

运动测试通过注入单调时钟模拟显示帧，避免依赖锁屏状态、屏幕刷新率及 XCTest 调度。覆盖 60/120Hz 一致性、丢帧、方向反转、速度限幅、打断、窗口缩放和精确收尾。原生视图测试验证连续 120 次位移不重新计算海报视图，以及远距离世界坐标的实际像素、原生命中坐标和可见内容更新时的位置一致性。

真实交互验收需使用 release 包，在相同窗口大小与同一曲库下对比快速横向、纵向、斜向滑动、反向滑动、鼠标拖拽松手、连续点选聚焦、缩放、窗口调整大小，以及卡片/列表/歌词滚动。该自动化测试不能代替实际显示帧耗时与肉眼验收。

本次自动化结果：上述专项测试 73 项全部通过。全量 246 项中 10 项跳过，235 项通过，`BugAuditTests.testLyricsSyncComparisonHydratesLightweightTrack` 一项失败；已在独立目录构建未修改的 HEAD，复现相同失败，确认是基线已有问题。

解锁后补充界面验证：启动 `.build/MiniVoice.app` 的 Release 进程，在实际 1,040 首曲库上操作纵向滚动、横向滚动指令与反向、斜向拖拽、海报聚焦、83%/100% 缩放、三种样式切换、简易/音乐库列表滚动、歌手卡片滚动及打开/返回。观测到内容更新、聚焦后播放器对齐和缩放比例正确，验收结束恢复音乐墙。该验证通过界面自动化操作并检查状态/截图，没有采集连续显示帧，不能据此宣称帧率或主观手感已追平 Folia。
