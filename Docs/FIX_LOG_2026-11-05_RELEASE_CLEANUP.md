# 正式渠道清理与音乐墙逐项修复

## 1. 正式构建与冗余入口

正式构建使用原 Mac/Android 体验实现及当前 iOS 宿主。删除 build-experience.sh、deploy-experience.sh、build-debug-app.sh，移除独立体验 IPA/DMG/应用身份的分支。保留 Debug/Release 编译配置；它们不再产生不同产品身份。

Mac DesktopPanels 删除旧 SwiftUI 设置、歌曲编辑窗口及专用菜单/输入窗口实现，只保留状态栏、全局快捷键和系统外观。Android 旧 MainActivity 上一轮已改为历史启动入口转发，本轮不删除此升级兼容入口。旧用户数据、旧已安装应用和历史产物不做破坏性删除。

## 2. Mac 点击卡片“无效的后台命令”与智能裁切

原因：前端已调用 artworkSubjects、Swift 已实现，但 Electron 允许列表遗漏该命令。加入正式宿主允许列表，并为可选的图像分析关闭全局错误弹窗；其他业务错误仍正常上报。增加允许列表回归测试，并检查打包 ASAR 中的实际命令。

用偏侧人脸检测结果的页面用例验证 Mac 会请求识别、裁切向主体偏移。页面验证使用合成检测结果；真实复杂封面识别准确性、头发完整度仍需逐图验收，不声称能够消除任意比例下的裁切。

## 3. 清晰/模糊切换偏移

移除模糊层独立居中与额外 48px 改变构图的尺寸规则。移动端模糊图放在同一插图容器，共享焦点位置和相同边界；Mac 模糊层复制清晰层尺寸、位置、变换原点和变换，并使用相同的动画帧。透明度切换只改变效果，不重算居中裁切。

## 4. 移动端缩放字体过大

iOS 双指期间不再把冻结的整份文字内容按比例放大。只保留普通封面缓存布局；当前卡片文字按实际尺寸排版，文字容器变换为 none。增加标题 14–26px、歌手 10–13px 的独立 CSS 上限与 WebKit 字号调整约束，歌词使用现有最高 34px 的尺寸模型。

连续缩小/放大的页面测试检查实际字体与变换，不以 React prop 或源码值代替渲染结果。实际 iPhone GPU 与跟手感仍待真机验收。

## 5. 展开后按钮右对齐

将自动剩余间距放在动态歌词按钮前；模糊/清晰、收起紧随其后，三项为一组靠右。非播放预览只有背景切换与收起时保留正确的右侧锚点。iOS、Android 页面检查按钮坐标间距和最右边界。

## 验证与产物

- 定向 Electron 页面回归：iOS/Android 字体缩放、右侧按钮组、模糊裁切；Mac 识别请求、偏侧主体裁切、清晰/模糊精确几何一致，全部通过。
- 定向桌面单测：正式身份、插图中间帧覆盖、识别命令入口通过；共享单测本轮运行 78 项通过。
- UI 门禁、版本检查、公开构建路由、iOS 导出脚本模拟测试、发布配置反例通过。
- Mac 正式 App/DMG、Android 正式 APK、iOS Release 模拟器构建通过；Mac 深度签名和 Android APK 签名验证通过。
- 全量桌面单测本轮有 2 项失败：kinetic.test.mjs 的估算逐字时间及初始字透明度断言，与当前分支正在变化的逐字歌词实现不一致；未屏蔽或修改这些用例，不声称全量通过。
- 本轮没有安装到真实设备，也没有覆盖 /Applications。产物按当前分支输出规则为 .build/dist/MiniVoice-3.0.0-mac.app、MiniVoice-3.0.0-mac.dmg、MiniVoice-3.0.0-android.apk。
